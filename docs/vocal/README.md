# 声乐主线

## 当前目标

把已有练声感觉转化为歌曲里的稳定能力，优先处理：

1. G4/A4 附近的质量和重复性，而不是只碰到音高
2. 小音量稳定发声与弱唱
3. 模糊旋律线的听辨、记忆和清唱复现
4. 中文母语者唱英文歌的节奏与咬字
5. 选调和改编，而不是强行保留原调

## 公开课程结构

网页课程现在分成四层：

1. **安全 / 定位：** 判断今天能否练，并留下可复测基线；
2. **短专项跟练：** 每条约 1–2 分钟，统一负责准备、钢琴示范/留空、移调间隔和收尾休息；
3. **教程 / 排错：** 解释动作、听感、常见错误和回退；
4. **路线 / 歌曲：** 前8单元决定练哪些卡，歌曲页负责把协调迁回真实歌词。

公开页面顺序为：安全与定位 → 日常跟练中心 → 基础发声 → 头声/换区/混声 → 弱唱 → 音准/听唱 → 英文节奏 → 前8单元 → 歌曲落地。

个人学习仍在吉他定位阶段；完整声乐主线尚未提前启动。吉他阶段可以使用日常跟练中心做每周 1–2 次短维护，但不更新正式声乐进度，也不替代未来定位。

## 吉他阶段的声乐维护

- 不再要求跑完固定 20 分钟大套餐；按当天状态选 2–5 张短卡，常见总时长约 8–20 分钟。
- 日常卡覆盖半闭合、哼鸣、元音、滑音、琶音和灵活性；专项页再处理头声/换区/混声、弱唱、听唱、英文与歌曲。
- 单条内部连续完成；条与条之间允许点手机，下一条不会自动冲入，重新给准备时间。
- 已拥有练声瓶；半闭合卡写“练声瓶 / 唇颤 / vv”时按当天器材选择。练声瓶型号和说明水位未确认前只遵循原厂说明。
- wu / ng / mum / gug / vv / da / lu 等音节配中文近似读法、口腔动作和浏览器读法示意，不默认用户认识英文练声缩写。
- 起音和当天上限只是工作设置，不是个人音域结论。
- 当天说话异常、疼痛、刺激感或持续沙哑时不练。
- 维护目标是保持轻起音、音准、动态和歌词迁移，不在吉他阶段追最高音。

## 正式声乐阶段

先做固定定位 VL-BASE-1。定位故意使用固定起音、次数和休息，不能被自动移调卡替代；之后用前8个训练单元决定每次练哪些短卡。

## 训练记录建议

每次只记录对复盘有用的最小信息：

- 日期与身体状态
- 做了哪些短卡 / 歌曲与调性
- 最难的一句或一个技术点
- 连续成功次数，而不是最高极限
- 是否挤、疼、刺或唱后持续沙哑
- 一段短录音链接
- 下一次只改一件事

## 安全边界

- “碰到一个音”不等于能用于稳定演唱。
- 练习目标是舒适、可重复、第二天可恢复。
- 出现疼痛、明显刺激感或持续沙哑时停止相关练习；需要时咨询合格的声乐教师或医疗专业人士。
- 本仓库不做嗓音疾病诊断。

## 首轮歌曲

- Don't Look Back in Anger：主歌减重、预副歌换挡、亮而窄的高区、英文重音与弱读。
- Falling Slowly：稳定音域、选调、最高音替代方案、用动态而非只靠音高制造高潮。
