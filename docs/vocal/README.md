# 声乐主线

## 当前目标

把已有练声感觉转化为歌曲里的稳定能力，优先处理：

1. `G4/A4` 附近的质量和重复性
2. 小音量稳定发声与弱唱
3. 模糊旋律线的听辨、记忆和清唱复现
4. 中文母语者唱英文歌的节奏与咬字
5. 选调和改编，而不是强行保留原调

## 训练记录建议

每次只记录对复盘有用的最小信息：

- 日期与身体状态
- 练习/歌曲与调性
- 最难的一句或一个技术点
- 连续成功次数，而不是最高极限
- 是否挤、疼、刺或唱后持续沙哑
- 一段短录音链接
- 下一次只改一件事

## 安全边界

- “碰到一个音”不等于能用于稳定演唱。
- 练习目标是舒适、可重复、第二天可恢复。
- 出现疼痛、明显刺激感或持续沙哑时停止相关练习；需要时咨询合格的声乐教师或医疗专业人士。
- 本仓库不做嗓音疾病诊断。

## 首轮歌曲

- *Don't Look Back in Anger*：主歌减重、预副歌换挡、亮而窄的高区、英文重音与弱读。
- *Falling Slowly*：稳定音域、选调、最高音替代方案、用动态而非只靠音高制造高潮。
