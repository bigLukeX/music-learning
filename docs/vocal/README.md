# 声乐主线

## 当前目标

把已有练声感觉转化为歌曲里的稳定能力，优先处理：

1. `G4/A4` 附近的质量和重复性
2. 小音量稳定发声与弱唱
3. 模糊旋律线的听辨、记忆和清唱复现
4. 中文母语者唱英文歌的节奏与咬字
5. 选调和改编，而不是强行保留原调

## 公开课程结构

网页课程已补齐为：定位基线 → 安全与恢复 → 日常练声与自动钢琴 → 气流/声带振动/声道协调 → 高音与换区 → 弱唱 → 音准与听唱 → 英文节奏 → 前 8 周 → 选调与歌曲版本。

个人学习仍在吉他定位阶段；完整声乐主线尚未提前启动。吉他阶段可以使用 [`src/content/docs/vocal/daily-practice.mdx`](../../src/content/docs/vocal/daily-practice.mdx) 的 20 分钟常规流程，状态不好时降为 8 分钟轻柔版；额外 10 分钟专项每周只轮换 2–3 次。它不更新声乐正式进度，也不替代未来定位。未来正式进入声乐主线时，先做 `src/content/docs/vocal/baseline.mdx`，再根据首个未通过能力决定首轮比重。

## 吉他阶段的声乐维护

- 每次约 20 分钟常规练声已经够用；专项 10 分钟不每天叠加。
- 浏览器钢琴提供常规20分钟、轻柔恢复、头声/换区、混声/闭合、元音、转音和听唱套餐。
- 已拥有练声瓶；播放器提供“有练声瓶”和“无练声瓶”两个完整版本。练声瓶只替代半闭合训练段，无瓶版使用唇颤音或 `vv`，后续元音、头声/混声、转音、听唱和歌词训练一致。
- 默认 `C3 → E4` 只是未定位前的保守工作设置，不是个人音域结论。
- 当天说话异常、疼痛、刺激感或持续沙哑时不练。
- 练声瓶型号和说明水位尚未确认；确认前只遵循设备原厂说明，不给通用厘米数。
- 维护目标是保持轻起音、音准、弱唱和歌词迁移，不在吉他阶段追最高音。

## 训练记录建议

每次只记录对复盘有用的最小信息：

- 日期与身体状态
- 练习/歌曲与调性
- 最难的一句或一个技术点
- 连续成功次数，而不是最高极限
- 是否挤、疼、刺或唱后持续沙哑
- 一段短录音链接
- 下一次只改一件事

## 安全边界

- “碰到一个音”不等于能用于稳定演唱。
- 练习目标是舒适、可重复、第二天可恢复。
- 出现疼痛、明显刺激感或持续沙哑时停止相关练习；需要时咨询合格的声乐教师或医疗专业人士。
- 本仓库不做嗓音疾病诊断。

## 首轮歌曲

- *Don't Look Back in Anger*：主歌减重、预副歌换挡、亮而窄的高区、英文重音与弱读。
- *Falling Slowly*：稳定音域、选调、最高音替代方案、用动态而非只靠音高制造高潮。
