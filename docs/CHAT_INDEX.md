## 新资料处理规则

1. 原件进入 `sources/` 或用户指定的只读外部位置。
2. 本页登记名称、日期、主题与可用范围。
3. 在对应 `docs/` 页面写原创摘要、结论和练习。
4. 不确定内容标为“待验证”，不因来自旧聊天就自动视为事实。
