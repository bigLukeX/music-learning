# 数学物理视角乐理

## 目标

建立从物理声学到音乐实践的桥梁，而不是把音乐简化成公式。

建议顺序：

1. 振动、周期、频率与波
2. 基频、驻波、泛音与音色
3. 八度、频率比与对数音高
4. 律制与 12 平均律的历史/工程妥协
5. 音程、音阶、调式与调性
6. 三和弦、七和弦与和弦外音
7. 结构音、和声功能与进行方向
8. 节拍、细分、重音、切分与律动
9. 在吉他、人声、口琴和歌曲里验证

## 讲解约束

- 物理解释声音如何产生，不自动等于音乐为何感人。
- 简单整数比有助于理解协和，但不能单独推出所有和声实践。
- 12 平均律不是把八度频率线性切成 12 份。
- 每个公式都要说明变量、适用条件和听觉意义。
- 每节至少有一个无需昂贵设备的听觉或乐器实验。

## 第一批页面

- 声音、频率与周期
- 弦的驻波与泛音列
- 为什么八度是频率翻倍
- 为什么半音倍率是 `2^(1/12)`
- 从 C 大调调内和弦到功能和声
