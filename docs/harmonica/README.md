# 布鲁斯 10 孔口琴

## 目标

把口琴作为旋律、节奏、即兴与呼吸乐句训练的支线，并与吉他弹唱连接。

## 已确认乐器

- A 调十孔口琴：按第二把位演奏 E 调布鲁斯
- Bb 调十孔口琴：按第二把位演奏 F 调布鲁斯
- 具体型号与是否为标准 Richter 调音仍待核对

没有 C 调琴不影响开始。孔位模式在两把琴上相同；教程默认 A 琴主练、Bb 琴移调复测。

## 建议阶段

1. 单音、孔位定位与稳定节奏
2. 中音区简单旋律
3. 第二把位：A 调琴演奏 E 调、Bb 调琴演奏 F 调
4. 2、3、4 孔吸音区域与基础 blues vocabulary
5. 压音的音高控制，而不是只追求“压下去”
6. 12 小节布鲁斯、短句、留白和 call and response
7. 与吉他伴奏或人声轮流回答

## 开始前待确认

- 两把琴的具体型号与调音系统
- 是否能稳定吹出单音
- 是否希望更偏旋律、布鲁斯即兴，还是弹唱间奏
