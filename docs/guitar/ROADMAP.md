# 完整吉他路线

这份路线忠实细化此前聊天中确定的阶段 0–9，不另起体系。

## 能力树

```text
节奏 ── 和弦 ── 技术
  │       │       │
指板 ── 音阶 ── 乐理
  │       │       │
听力 ── 扒歌 ── 表达
            │
      ┌─────┴─────┐
   民谣/指弹     电吉他/音色
      └─────┬─────┘
        即兴 / 编曲
```

最容易被忽略、但必须长期保持的是：**节奏、耳朵、指板**。

## 阶段 0：基本操作——能完整弹歌

### 内容

- 持琴、拨片、左右手姿势与调音
- 六根空弦音名、标准调弦 `E A D G B E`
- 常用开放和弦和基础换和弦
- 四分/八分音符、基础扫弦与分解
- 节拍器、和弦谱、六线谱与 TAB

### 通关

- 调音和基本准备能独立完成
- 能在稳定拍子中连续弹 8 小节；错音时不停车
- 至少一首简单歌能从头到尾完成

## 阶段 1：节奏吉他基础——从“按对”到“像音乐”

### 内容

- 十六分音符网格、切分、附点、三连音
- 空拍、重音、闷音、palm mute
- 大横按、F/Bm、Power Chord、移动和弦
- 变调夹原理和常见和弦进行
- 跟鼓机或节拍器保持 groove

### 通关

- 能口数并弹出八分与十六分细分
- 能把重音移动到指定位置
- 面对同一进行，能选择开放和弦、封闭和弦或 power chord，并说明理由

## 阶段 2：技术与旋律——从伴奏手到吉他手

### 内容

- 击弦、勾弦、滑音、推弦、揉弦、泛音、双音、八度
- 跨弦、交替拨弦、连续八分/十六分、基础消音
- 演奏歌曲前奏、间奏、vocal melody 和 riff

### 通关

- 技术动作在慢速下音头清楚、杂音受控
- 推弦能用目标音对照，而不是只凭手感
- 能演奏至少三个短旋律/riff，其中一个来自自己耳扒

## 阶段 3：指板——第一次大升级

### 内容

- 6/5 弦所有音和八度关系
- CAGED 五形
- 大/小调音阶与大/小五声音阶
- 根音、三音、五音定位
- 音阶不只背 box，要知道音级功能

### 通关

- 随机给出 6/5 弦自然音位置，能快速找到
- 给定调性，能说出音阶音并在一个区域弹出
- 能从一个根音找到常用八度、三音和五音

## 阶段 4：和声——知道为什么

### 内容

- 音程、大调结构、大小三和弦
- 大/小调自然和弦与七和弦
- sus2、sus4、add9、slash chord、转位
- 借用和弦、副属和弦
- Triad 在多个弦组和转位中的位置

### 通关

- 能从音阶构建调内三和弦
- 能解释常见进行的级数与方向
- 同一个和弦至少能给出三种可用 voicing

## 阶段 5：耳朵与扒歌——从学生到演奏者

### 固定扒歌顺序

1. Bass / 根音运动
2. 和弦性质
3. 节奏与重音
4. 顶部旋律或 riff
5. 装饰音、演奏法
6. 音色、动态和声部位置

### 通关

- 能自己找出 2–4 小节简单旋律
- 能记录一首歌的段落、根音、主要和弦和节奏
- 能说明哪些是确定听到、哪些是推断、哪些仍待验证

## 阶段 6A：民谣 / 木吉他

- PIMA、Travis picking、alternating bass、拇指独立
- 分解变化、melody + bass、chord melody
- Drop D、DADGAD、`FACGCE` 等特殊调弦
- 泛音编曲、自弹自唱 arrangement

结果：用较少的音，做出完整的弹唱或独奏织体。

## 阶段 6B：电吉他

- 精确 palm mute、左右手消音
- Power chord / octave riff、tremolo picking
- 推弦音准、揉弦、legato、交替拨弦
- 后期再学习 economy、sweep、tapping
- 信号链与音色：gain、EQ、drive/fuzz、modulation、delay、reverb

结果：先控制需要响和不能响的音，再追求速度和复杂度。

## 阶段 7：即兴

- 五声音阶、chord tone、target note
- Motif、call and response、phrasing、留白
- 大小五声音阶混合、调式

通关：能跟随和弦变化落到目标音，而不是在一个 box 内随机跑。

## 阶段 8：编曲与乐队意识

- 双吉他分工，与 Bass/Vocal 避让
- 音区、转位、部分和弦、双音、八度
- Texture、dynamics、留白

通关：能给同一进行做至少两层互不打架的吉他声部。

## 阶段 9：高阶整合

- 全指板和弦、Triad、四声部、drop voicing
- Chord melody、reharmonization、voice leading
- Modal interchange、chromatic harmony
- Advanced rhythm、odd meter、polyrhythm
- 完整 transcription、即兴作曲和 arrangement

最终状态：**听到音乐 -> 知道大致发生什么 -> 手上能找到 -> 能改成自己的版本。**
