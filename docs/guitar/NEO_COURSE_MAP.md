## 完成基础后的两条进阶路线

### 路线一：风格特训

- Blues
- Funk
- R&B

这些风格课用于形成演奏语言，不替代基础模块。

## 如何使用课程而不是“刷课”

每次课程后做四步：

1. **复述**：不用视频，说出本课解决什么问题。
2. **慢练**：用能控制的速度完成动作。
3. **迁移**：把概念放进一首歌或 2–4 小节音乐任务。
4. **记录**：在 `PROGRESS.md` 写通过证据和剩余问题。

只有“看完”不算完成；能在歌曲、扒带或自由演奏中复现才算进入能力树。
