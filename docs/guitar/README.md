# 吉他主线

这里是当前优先完成的学习模块。吉他部分完成后，项目会继续推进乐理、声乐、歌曲分析和口琴。

## 四份核心文件

1. [`ROADMAP.md`](ROADMAP.md)：完整能力路线与阶段通关标准
2. [`NEO_COURSE_MAP.md`](NEO_COURSE_MAP.md)：NeoMusic 课程如何嵌入路线
3. [`NEXT_8_WEEKS.md`](NEXT_8_WEEKS.md)：定位测试和前 8 个训练周的每周三练计划
4. [`PROGRESS.md`](PROGRESS.md)：基线、周复盘与通关记录

## 学习原则

- **四线并行**：节奏、技术、指板、耳朵每周都碰，歌曲负责整合。
- **不断拍优先**：错音可以复盘，但演奏中先维持时间流动。
- **听力从第一天开始**：不等“乐理学完”才扒歌。
- **标准调弦先建立地图**：`FACGCE` 可以玩，但系统深入放到标准调弦逻辑稳定以后。
- **电吉他先控制噪音**：消音、节奏、推弦音准、揉弦早于速度。
- **课程不是进度条**：NeoMusic 一课只有在动作和音乐任务中可复现，才算完成。

## 当前入口

先完成 [`NEXT_8_WEEKS.md`](NEXT_8_WEEKS.md) 的“定位练习 A/B”。定位决定从阶段 0 的补课或哪个训练周开始，不改变整条路线；尚不会整曲或 riff 可以如实记录，不需要先练会才允许定位。

NeoMusic 交错顺序沿用已登记的历史路径图；三份 PDF 的主题与页码本轮已核对，App 视频编号仍待确认，见 [`NEO_COURSE_MAP.md`](NEO_COURSE_MAP.md)。前 8 个训练周只进入“音符篇 + 节奏 1–6 + 机能篇”，和声与 CAGED 不提前。默认每个自然周练 3 次，一个训练周跨两个自然周。

## 第 16 训练周之后

执行 [第 17 训练周后：扒歌、分支与作品关卡](../../src/content/docs/guitar/post-16-gates.mdx)。每关六次、每周三次、每次 45 分钟不变；把 Neo 块 2–7 尚未练到的内容逐项接入正在做的作品，不先刷完全部课件。

阶段 0–9、A–D 与 Neo 的对照，以及吉他之后进入理论→声乐→歌曲→口琴的准确条件，统一见 [完整路线的交接验收](ROADMAP.md#handoff)。这里说明课程怎样推进，真实状态仍只写入 `PROGRESS.md`，本次课程修订不代表个人通过任何关卡。
