# 吉他主线

## 当前定位

吉他是弹唱、乐理理解、扒歌和编配工具。现阶段按初学路线推进，不假设已经具备稳定横按、复杂节奏或完整扒谱能力。

## 顺序

1. 持琴、调音与基础安全
2. 开放和弦与慢速换和弦
3. 节拍器、四分/八分音符与基础扫弦
4. 6/5 弦根音与八度形状
5. 指板是六条错开的半音阶
6. 调内和弦与常见进行
7. 变调夹、移调与适配人声音域
8. TAB、节奏记号与歌曲结构
9. 特殊调弦和开放弦和声
10. 扒歌与一把吉他编配

## 已讨论的关键模型

- 标准调弦为 `E A D G B E`；大部分相邻弦是纯四度，G–B 为大三度。
- 每升一品升高一个半音；12 品回到高八度同名音。
- `FACGCE` 只改变 6、4、2 弦，开放弦形成接近 `Fmaj9` 的音集合，适合研究持续开放音与 Midwest emo 色彩。
- 录音中的和弦、主旋律、过门、装饰和多轨声部应分开听；一把吉他不必同时复刻全部声部。

以上是课程入口，具体音高、指法和安全调弦建议写成正式页面时仍应复核。
