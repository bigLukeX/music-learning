# 歌曲练习与分析

歌曲页的目的不是收藏资料，而是把一首歌变成可执行的训练项目。

## 统一模板

每首歌建议包含：

- 训练目的
- 版本与来源
- 调性、速度、拍号（注明证据或待验证）
- 段落结构
- 和声骨架
- 人声音域与难点（区分主唱、和声和不同版本）
- 中文母语者的咬字/节奏难点
- 吉他伴奏的最小可演出版本
- 降调、局部降八度、改旋律、假声/头声等备选方案
- 分段练习、通过标准与录音复盘
- 版权合规的短提示；不保存完整歌词或完整未授权 TAB

## 第一批案例

### Don't Look Back in Anger

重点：主歌不要唱重、进入副歌前减重、`G4/A4` 区域稳定性、重音骨架、弱读、词间连接、元音承载时值。

### Falling Slowly

重点：不要把偶尔碰到的最高音当成可用音域；比较整体降调、局部降八度、改旋律与轻声方案；用扫弦、节奏、动态和和声厚度维持高潮。

### Where We've Been

重点：复核旧聊天中的和弦与段落判断；分析大小和弦色彩变化；做一把吉他可演出的简化编配。不得直接搬运完整歌词。

### When You Sleep（Friko 版本）

重点：以原曲结构作为地图，但把翻唱当作独立版本复核；拆分和弦、主题旋律、过门、装饰与多轨声部；根据个人能力决定保留哪些声部。
