## 概念版与吉他版

会认音名和全半音，就能做概念版；吉他版接在[第 9–12 训练周](../../guitar/stage-b-weeks-9-16/)相关关卡之后。手上暂时没有 triad（只保留根、三、五音的三和弦形状）时，先用键盘或逐音弹奏，不据此跳过吉他先修。

## 三和弦与七和弦

从根音隔一个音取一次音：C 大调中 `C–E–G` 是 C 大三和弦，`D–F–A` 是 D 小三和弦。`3、b3` 相对**当前和弦根音**，不是固定相对歌曲主音。

| 类型 | 相对根音 | C 根音例子 |
|---|---|---|
| 大三 | `1–3–5` | C E G |
| 小三 | `1–b3–5` | C Eb G |
| 减三 | `1–b3–b5` | C Eb Gb |
| 大七 | `1–3–5–7` | C E G B |
| 属七 | `1–3–5–b7` | C E G Bb |
| 小七 | `1–b3–5–b7` | C Eb G Bb |
| 半减七 | `1–b3–b5–b7` | C Eb Gb Bb |

半减七是在**减三和弦**上加小七度，不能归为保留纯五度的小三和弦底。

## 10 分钟构造实验

在 `C D E F G A B` 上轮流从每个音隔音取三音；写出 7 个结果，再看下表核对。每个和弦按根、三、五逐音弹，每音 1 秒，做 2 轮。

| 级数 | 和弦 | 音名 |
|---|---|---|
| I | C | C E G |
| ii | Dm | D F A |
| iii | Em | E G B |
| IV | F | F A C |
| V | G | G B D |
| vi | Am | A C E |
| vii° | Bdim | B D F |

通过：合上表重建 7 个三和弦，说明 Dm 的 F 为什么是小三度。错了就只保留 C/Dm，按半音核对三音，下一次再扩展。

## 为什么进行有方向

方向来自低音、共同音、半音趋向、拍子位置、重复经验和风格语法。C 调的 `G7→C` 中，B 可以上行到 C，F 可以下行到 E。单独一个和弦名不会决定永久功能。

**4 分钟对照：** 分别弹 `B→C` 与 `F→E`，每音 2 秒，各 3 次；再听/弹一次 G7→C。能指出两条声部的方向就通过。不会同时按和弦时保留单音，不加速。

## 一个可直接弹的 Voice Leading 例子

下面是本站自编的 C–G–Am–F 例子，标准调弦。数字按 **3 弦、2 弦、1 弦**排列，只弹这三根弦，其余弦消音：

| 和弦 | 3/2/1 弦品位 | 从低到高的音 | 最高音 |
|---|---|---|---|
| C | `5 / 5 / 3` | C E G | G |
| G/B | `4 / 3 / 3` | B D G | G |
| Am/C | `5 / 5 / 5` | C E A | A |
| F/C | `5 / 6 / 5` | C F A | A |

斜线后是最低音：G/B 的根音仍是 G，低音是 B。最高声部为 `G–G–A–A`；转位让声部少移动，不必每次回根音最低的排列。

**8 分钟吉他版：** `4/4，60 BPM`，每个和弦一小节，第 1 拍拨响、保持至小节末；4 小节循环 3 次，再录一次熟悉的开放和弦版。分别比较最高音、低音与密度，不把多种变化硬归因于一个因素。通过：三弦音清楚、3 次不断拍，能指出 G/B 的根音/低音。失败时逐音核对，再降为每 2 小节换一次；疼痛立即停练。

## 和弦外音、借用与副属

和弦外音不是当前和弦的组成音，但可以连接旋律。例如 C 和弦上唱 `C–D–E`，D 可作为连接 C/E 的经过音。

**4 分钟：** 固定 C 和弦，以 `60 BPM` 弹 `C4 D4 E4 休止`，每格一拍，重复 3 次；再把 D 换成休止，重复 3 次。能指出 D 不在 C–E–G 内、却连接旋律就通过；找音困难时先写音名，不同时弹伴奏。

借用和弦常从平行大小调取音，例如 C 调用 Fm；副属临时指向一个调内目标，例如 `D7→G→C` 中 D7 指向 G。后续在 Neo 相应主题确认一个短例，再分析解决位置；未通过三和弦实验时，把这两项保留为路线预告。
