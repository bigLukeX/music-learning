## 这套教程怎么学

1. 每次只做当前页面给出的任务，不按兴趣随机跳章。
2. “看完”不等于完成；必须留下录音、节拍器速度、TAB、音名或文字复盘之一。
3. 通关标准优先看稳定、可重复和能否从错误中继续，不追求一次性的极限表现。
4. 个人录音和进度默认留在本地，不自动进入公开网页。

从 [完整课程目录](./course-outline/) 看全貌，或直接开始当前唯一任务：[吉他定位练习 A](./guitar/positioning-a/)。

当前练习需要听觉参照时，打开[听觉实验室](./listening-lab/)；到第 16 训练周后按[作品关卡与交接](./guitar/post-16-gates/)继续。
