## 先做歌曲地图

记录段落、最低/最高音、最长高音、最密歌词、换区位置与情绪峰值。难度不能只用最高音判断：持续时长、元音、进入方式、前后句疲劳都会改变实际难度。

## 四种处理方法

1. **整体降调：** 保留旋律关系，改变全曲音域；
2. **局部降八度：** 保留高潮结构，但改变某句位置；
3. **改旋律：** 保留和声与情绪，选择更适合的落点；
4. **改变声音配置：** 更轻、更多头声比例或更窄元音，但必须可重复。

没有一种方案天然“更忠于原作”。个人版本的标准是：结构和情绪成立，同时身体可持续。

## 分段流程

说歌词节奏 → 单音说唱 → 元音旋律 → 原词慢速 → 原速短句 → 两句连接 → 完整段落 → 完整歌曲录音。

## 首轮应用

- *Don't Look Back in Anger*：避免主歌先唱重；预副歌前留出减重空间；高区先确定承载元音；重读词落进稳定拍点。
- *Falling Slowly*：比较原调与不同降调；为最高点准备整体降调、局部降八度和改旋律三版；用伴奏密度与动态共同制造高潮。

## 通关

一首歌在选定调性中能完整唱完；主要难句有可重复方案；结束后说话状态正常；录音中动态和语言服务于表达，而不是全程同一力度。
