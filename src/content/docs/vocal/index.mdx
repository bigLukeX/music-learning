<details>
<summary>完整声乐路线与正式关卡</summary>

安全与固定定位 → 连续发声、轻起音、元音 → 头声与换区 → 混声和歌词连接 → 弱唱与动态 → 音准与旋律记忆 → 英文语流 → 选调与歌曲整合。

正式声乐阶段先做[固定基线](./baseline/)，再按[前8个训练单元](./first-8-weeks/)安排重点。吉他主线期间的短维护不代表已经完成声乐定位，也不自动推进个人进度。

跟练器负责把实际操作排好，教程负责解释原理、听感和错误回退。既不要求先学会一大页设置，也不把教程知识删掉。

完成播放只是走完流程。通关仍需要同条件跨日复现、可比较的短录音，以及在歌词或陌生素材里的迁移；不把“播放到最高音”当成能力成绩。
</details>
