## 声乐模块现在怎么用

声乐页面分成四种职责，不再把所有东西塞进一条长播放器：

1. **安全与定位：** 判断今天能不能练、固定基线；
2. **跟练：** 每条约 1–2 分钟的短专项，负责真正开口练；
3. **教程：** 解释动作、听感、错误和回退，不要求边唱边读；
4. **路线与歌曲：** 决定这次选哪些卡，并把结果迁移到真实歌词。

## 两个入口

- **吉他主线期间：** 每周可选 1–2 次声乐维护，直接进[日常练声与专项跟练中心](./daily-practice/)，选 2–5 条短卡即可；
- **正式声乐阶段：** 先读[安全练习](./safe-practice/)，完成[固定基线](./baseline/)，再用[前 8 个训练单元](./first-8-weeks/)决定每次练哪些卡。

网页内容建好不等于个人能力已通过；仍然按真实录音、重复次数和练后状态推进。

## 能力路线

| 阶段 | 核心问题 | 实际练习入口 |
|---|---|---|
| 0 安全 / 定位 | 今天能否练，从哪里开始 | 安全页 + 固定基线 |
| 1 基础协调 | 连续发声、轻起音、元音 | [基础发声](./breath-phonation-resonance/) |
| 2 日常基本功 | 半闭合、哼鸣、滑音、琶音、灵活性 | [跟练中心](./daily-practice/) |
| 3 头声 / 换区 / 混声 | 高处减少多余用力并能上下连接 | [头声换区混声](./high-notes-and-mix/) |
| 4 弱唱 / 动态 | 小声仍有音高和文字 | [弱唱](./soft-singing/) |
| 5 听唱 / 英文 | 记旋律、让英语落进拍子 | [听唱](./pitch-and-ear/) + [英文节奏](./melody-and-english/) |
| 6 歌曲整合 | 选调、难句、前后连接 | [歌曲落地](./song-application/) |

## 跟练中心与专项页的关系

[日常跟练中心](./daily-practice/)放最常用的“基础体能”：半闭合、哼鸣、元音、滑音、mum 琶音、da 灵活性。专项页不是重复它，而是针对一个问题给更有目的的卡。

例如：

- 高处一喊：日常半闭合热身 → 高音页的轻 wu / ng→u；
- 弱声漏气：基础 vv → 弱唱页的长音 / 中弱对照；
- 旋律记不住：听唱页的 1–2–1 回声 → 听觉实验室两小节；
- 英文拖拍：英文页的重音骨架 → 完整音节 → 单音 → 最小旋律。

## 教程应该什么时候看

第一次不知道卡片在练什么，或者连续两次卡在同一问题时，再读对应页下面的解释和排错。平时练习不需要从头读教程。

## 怎样判断进步

完成一张卡只代表流程走完。真正的证据是：

- 同一条在两个练习日都能舒服复现；
- 起音、节奏或动态的差异能从录音里听见；
- 新音区不靠突然增加音量完成；
- 换到一句歌词或陌生素材后仍能保留；
- 练后自然说话和平时一样。

钢琴只提供音高、节奏和留空结构，不是真人范唱，也不能判断内部声带动作。听不出自己的差异时保留短录音，请教师帮助校准。
