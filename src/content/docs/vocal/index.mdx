这是已会练法后的伴练：准备倒数 → 跟琴唱 → 留拍换气 → 自动换调。普通练习不强制示范；听唱专项才保留先听与留空。每项结束后手动继续，下一项仍重新准备。

字典、练声瓶和音量说明见[日常跟练页](./daily-practice/)，平时不用先读。

<details>
<summary>教程和正式关卡</summary>

安全与固定定位 → 连续发声、轻起音、元音 → 头声与换区 → 混声和歌词连接 → 弱唱与动态 → 音准与旋律记忆 → 英文语流 → 选调与歌曲整合。

正式声乐阶段先做[固定基线](./baseline/)，再按[前8个训练单元](./first-8-weeks/)安排重点。吉他主线期间的短维护不代表已经完成声乐定位。

“知道怎么练”不等于所有能力已经稳定。通关仍需要同条件跨日复现、可比较的短录音和歌曲迁移；不能把播放完成或控件上限当成绩。

疼痛、沙哑或说话费力时停止，见[安全练习](./safe-practice/)。
</details>
