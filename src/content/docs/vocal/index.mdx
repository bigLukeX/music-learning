## 当前背景与目标

已经接触过“小猫叫、惊讶声、欢呼、混声”等练习感觉，下一步是把它们迁移到真实歌词和旋律。`G4/A4` 附近的质量、弱唱、旋律记忆和英文语流仍待个人定位；网页中的音高初值不是音域结论。

## 两个入口

- **吉他主线期间：** 可选每周 1–2 次声乐短维护，从[日常练声](./daily-practice/)选一次约 20 分钟整体流程，忙时用短版；缺一次不补。它不推进正式声乐周号。
- **正式声乐阶段：** 吉他阶段完成后，先读[安全练习](./safe-practice/)，做[固定基线](./baseline/)，再进入[前 8 个训练单元](./first-8-weeks/)。每单元按通关证据推进。

日常页的轮换池只帮助选择当次项目，不是七天每天都练的课表。

## 能力路线

| 阶段 | 要解决的问题 | 能留下的证据 |
|---|---|---|
| 0 安全与基线 | 今天能否练、从哪里开始 | 固定材料、音高、速度和练前/练后状态 |
| 1 稳定发声 | 轻起音、连续发声、元音变化 | 同一短型三次接近，进入一句歌词 |
| 2 换区与高音 | 音高上升时减少多余用力 | 舒适范围内重复短句，实际最高音有记录 |
| 3 弱唱与音色 | 小声仍有音高和清楚文字 | 同音高弱/中动态与一段渐弱 |
| 4 听唱与语言 | 记住旋律，让英语落进拍子 | 两小节脱离示范回唱、原创英文句子节奏 |
| 5 歌曲整合 | 选调、分句、动态与恢复 | 两个日期可比较的完整版本 |

## 课程地图

1. [安全练习](./safe-practice/) → [声乐定位](./baseline/)；
2. [气流、声带振动与声道](./breath-phonation-resonance/)：基础动作与三音短练习；
3. [日常练声与自动钢琴](./daily-practice/)：已有动作的参考音、移调与回声；
4. [高音与混声](./high-notes-and-mix/) → [弱唱](./soft-singing/)：具体短型、录音核对与回退；
5. [音准与听唱](./pitch-and-ear/) → [英文节奏](./melody-and-english/)；
6. [前 8 个训练单元](./first-8-weeks/)：自动与手动任务对应；
7. [歌曲落地](./song-application/)：选调实验与完整录音。

## 怎样判断进步

先比较同一任务在相同条件下的连续成功次数，再用一条陌生但同难度的素材检查迁移。记录实际唱到的音、歌词清楚度、节奏和恢复状态。完成播放器，只表示音序列播放完；提高上限控件，也不表示唱过或通过了新音区。

钢琴给参考音，浏览器语音给读法示意；它们不演示真人唱法，也不能判断你是否已经获得某种混声协调。听不出录音差异时，保留短录音请教师帮助核对，不靠加音量反复试。
