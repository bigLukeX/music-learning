## 先固定条件

先读[安全练习](../safe-practice/)。疼痛、刺痛、明显刺激、嗓音沙哑或说话费力时不做定位；今天休息，恢复后再安排。

选一台录音设备，放在口前约 30–50 厘米处，记下实际距离并保持不变。使用同一录音模式、房间和伴奏音量；如果软件自动调节音量，记录这一点，别把录音响度变化直接当成自己的动态变化。第一次只定基线，不当天反复刷新最好成绩。

## 固定测试包 VL-BASE-1

音级 `1–2–3` 表示大调前三音。例如以 C 为根音时是 C–D–E；起音不舒服就整体移调，**记下实际起音后，以后用同一设置复测**。每拍一秒即 `60 BPM`。

| 测试 ID | 固定任务 | 次数、休息与观察 |
|---|---|---|
| VL-SPEAK | 自然说“今天我用舒服的音量练习，结束后再比较一次。” | 练前/练后各一次；比较沙、低、费力或刺激感 |
| VL-ONSET | `mum` 唱 `1–2–3–2–1`，每音一拍，60 BPM | 3 次，每次后休息 5 秒；听音头、目标音和句尾 |
| VL-DYN | 同一舒适音唱 `wu` 4 拍：中声一次、较弱一次 | 作为一对做 3 对，次间休息 4 拍；弱声仍应可辨音高 |
| VL-EAR | [听觉练习室](../../listening-lab/)选择两小节素材 `E2-v1`，60 BPM；默认C3起，若不舒服整体移调并记录 | 先听 3 次，留空回唱一次，再揭示答案；记素材ID、起音、移调量/BPM与主要落点 |
| VL-EN | [英文节奏页](../melody-and-english/)的两句原创句子，60 BPM | 说重音骨架一次、补全音节一次；记录拖拍的位置 |
| VL-SONG | 一首熟悉且舒适的歌，固定版本、调性和伴奏 | 一遍录完；若太长，固定同一完整段落，记起止位置 |

不认识 `mum/wu` 时先看[音节字典](../daily-practice/#syllables)。允许先只做说话、轻起音与动态，休息后另一次完成听唱和歌曲；记录测试日期，不在疲劳时补完。

## 可选换区观察 VL-BRIDGE

只有 VL-ONSET 舒适且练后说话正常时才做。先用 `wu` 唱同一个 `1–2–3–2–1` 短型，每音一拍，60 BPM；一处最多 3 次、次间休息 5 秒。全部舒服才移高一个半音，本次最多试 3 个起音位置。首次明显变大声、挤压或音质下降就停止上移，记录位置，不测试极限。

以后先在原来成功的同一位置复测，再决定是否尝试新位置。未经过换区并不算失败，也不需要向 `G4/A4` 靠拢来完成定位。

## 怎样给自己反馈

1. 播放参考音或素材，先听一遍；
2. 回放自己的录音，只听一个维度：节奏、关键音或音头；
3. 用琴核对怀疑的音，写“确认/待核对”，不编造偏差数值；
4. 三次中有一次明显不同，就保持或降低难度；
5. 练后说话异常，停止当天发声，按安全页休息与复查。

“更轻松”的感觉有用，但不能单凭感觉判断内部声带动作。若始终听不出清楚与漏气的区别，把这三个短录音交给教师核对。

## 记录模板

```text
测试包：VL-BASE-1；日期：
设备/房间/距离/录音模式：
VL-ONSET：起音__，实际最高音__，60 BPM，接近__/3
VL-DYN：音高__，弱声是否仍清楚__，接近__/3对
VL-BRIDGE：未做/起音位置__，首次失稳__
VL-EAR：素材名或ID__，起音__，BPM__，关键落点__/__
VL-EN：60 BPM，最易拖拍的音节__
VL-SONG：歌曲/版本/伴奏/调性/BPM/起止位置__
练前/练后说话：
录音文件：
下一次保持相同的条件：
```

复测先做同题同设置，再增加一条陌生的同难度听唱题。录音命名与跨日比较沿用[歌曲录音复盘](../../songs/recording-review/)。

## 从哪里继续

- 起音或舒适中音不稳：[基础协调](../breath-phonation-resonance/)；
- 上行时追加用力：[换区短练习](../high-notes-and-mix/)；
- 小声只剩气声：[弱唱短练习](../soft-singing/)；
- 旋律或语流先失稳：[听唱](../pitch-and-ear/)与[英文节奏](../melody-and-english/)；
- 基本动作可复现：[前 8 个训练单元](../first-8-weeks/)。

定位只决定练习比重，不删除其他能力线。
