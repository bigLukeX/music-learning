## 每次正式练习怎么拼

一次正式练习通常约 20–30 分钟：

1. 状态检查 1–2 分钟；
2. [日常跟练中心](../daily-practice/)选 1–2 条轻热身；
3. 本单元选 2–3 条目标卡；
4. 歌曲迁移 1 条或两小节听觉任务；
5. 安静回听、记录和说话复查。

**不是把页面上的所有卡都做完。** 单条练习已经包含准备、示范/留空、移调间隔和收尾休息；条与条之间由你自己点下一条。

## 八个单元

| 单元 | 目标卡 / 任务 | 通关证据 |
|---|---|---|
| 1 基线与轻起音 | 基础页：vv/zz 4拍 + mum 三音 | mum 多次接近；练后说话正常 |
| 2 元音与持续发声 | 基础页：五元音链；弱唱页：轻元音4拍 | 至少3个元音切换不明显跑调，长音句尾仍清楚 |
| 3 头声与换区 | 高音页：半闭合换区五音 + 轻 wu 三音 + wu 滑音 | 高处不被迫变大声；上下连接正常 |
| 4 混声与歌词连接 | 高音页：mum 琶音 / gug 五音；歌曲页：先元音后原词 | 专项协调能进入一条真实歌词 |
| 5 弱唱与动态 | 弱唱页：中声→弱声 + 4拍渐弱 | 弱声仍有音高和文字，渐弱句尾不塌 |
| 6 音准与旋律记忆 | 听唱页：1–2–1 / 1–3–1 回声；再做 E2-v1 | 两个练习日保留两小节主要节奏与关键落点 |
| 7 英文语流 | 英文页：重音骨架 → 完整音节 → 单音 → 最小旋律 | 两遍两小节不加拍；旋律加入后语流不散 |
| 8 个人歌曲版本 | 歌曲页：元音→原词、相邻调A/B、四层迁移 | 两个日期有可比版本；难句有稳定方案和备选 |

## 同一单元怎么练四次

1. **第一次：** 只学最小卡组，熟悉提示和音型；
2. **第二次：** 同条件复现，回听只修一个问题；
3. **第三次：** 把协调迁移到歌词或新素材；
4. **第四次：** 同条件复测，写通过 / 部分 / 未通过及证据。

没有通过时，不需要重来整条路线。已经稳定的能力保留最小剂量，主要时间给最弱的一项。

## 什么时候加难

优先级是：**先重复稳定 → 再扩大音域 / 速度 / 语言复杂度。**

例如转音先逐音准确再加速；换区先在舒适范围上下连接，再提高上限；英语先固定拍位，再迁移到真实歌曲。

## 第 8 单元的交付

- VL-BASE-1 同题同设置前后比较；
- 一条舒适换区专项的跨日复现；
- 一组中/弱声与渐弱；
- 固定两小节素材的隔次复现 + 一条陌生同难度题；
- 一条英文或歌曲句子的拍位记录；
- 一首歌或完整段落的两个日期版本；
- 下一阶段唯一主要问题。

“通过”只表示这些行为可复现，不表示自动掌握所有混声、高音、转音或英文风格。
