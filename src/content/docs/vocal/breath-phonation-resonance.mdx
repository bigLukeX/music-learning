## 先建立一个够用的模型

呼气提供能量，声带振动产生声音，咽腔、口腔、舌和唇组成的声道改变最后听到的频谱。这个“声源—过滤”模型只是入门简化；音高、响度、元音会互相影响。

这里常见的几个词只这样理解就够：

- **支撑：** 呼气稳定、可控，不等于吸得特别满或腹部一直硬顶；
- **闭合：** 描述发声协调，不是让你主动夹喉咙；
- **共鸣位置：** 可以当感觉提示，不是把声音真的“塞”进额头或鼻子。

## 四条基础卡分别在练什么

### 1. vv / zz · 4拍连续

目标不是憋一口更长的气，而是让四拍里的声音从头到尾差不多。若后两拍越来越紧，先缩短，不要靠加气流撑住。

### 2. mum · 轻起音三音

听音头：

- “哈……mum”：气先漏出来，再出现音高；
- “MUM！”：音头猛撞、突然变大；
- 音高和声音一起自然出现：保留这个动作。

三音本身不是为了练高音，而是为了让起音和换音足够简单、可重复。

### 3. 同音高五元音链

换 i–e–a–o–u 时，音色本来就会变；本条只要求音高和响度不要跟着大幅漂移。某两个元音一换就挤，就先只练最顺的两个。

### 4. 一句歌词三层迁移

说节奏 → 只唱元音 → 原词。目的不是把辅音删掉，而是确认：原词一回来时，之前舒服的发声有没有被语言动作破坏。

## 半闭合工具为什么放在前面

唇颤、vv/zz、吸管或合适的练声瓶都会增加一定的口端阻力，常被用来帮助建立较轻的发声协调。但它们只是工具，不等于最终唱歌动作；练完仍要回到开放元音和歌词。

练声瓶只按原厂说明装配。需要猛吹、头晕、咳嗽或喉部不适时立即停止。

## 常见问题怎么退

| 现象 | 回退 |
|---|---|
| 4拍后半越来越紧 | 改成2拍声/4拍休息，或结束 |
| mum 音头像撞出来 | 降低音量，先做连续 vv |
| mum 前面先漏一口气 | 缩成一个轻单音，再回三音 |
| 换元音就跑调 | 只保留两个最顺的元音 |
| 原词一加就挤 | 回到元音层或一个词，不反复唱整句 |
| 疼痛、刺激、沙哑或说话费力 | 当天停止发声 |

## 通关标准

同一起音下，mum 三音能多次接近；至少三个元音切换不明显带跑音高；一条舒适歌词能从元音层接回原词；练后说话正常。下一次同条件还能复现，再增加范围或复杂度。

可听声学模型可参考 [UNSW Voice Acoustics](https://phys.unsw.edu.au/jw/voice.html)；半闭合工具的经典物理讨论可参考 [Titze 的研究](https://pubmed.ncbi.nlm.nih.gov/16671856/)。
