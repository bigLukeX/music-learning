:::tip[两种练习别混在一起]
上面的短卡练“听一句、留空回一句”；下面的听觉实验室任务练真实的两/四小节记忆。短卡是基本功，不能替代长一点的素材。
:::

## 先把听唱闭环做对

正确顺序是：**听完整一句 → 在心里预听 → 留空时自己唱 → 再核对。**

如果钢琴一响你就同步跟着唱，你练到的是追随，不是记忆。所以上面的回声卡会故意把钢琴停掉，把时间留给你。

## 四张短卡怎么用

- 1–2–1：最小距离，先确认能回到主音；
- 1–3–1：扩大到三度，开始建立比较明确的音级感；
- 1–5–1：跨度更大，范围不舒服时直接跳过；
- 短旋律：把“上、下、重复”的轮廓连成一句；
- **不规则旋律 · 延迟4拍回唱：** 听完 `1–3–2–5–3` 后安静等 4 拍，再唱，再只听钢琴核对。它专门减少“靠音阶惯性顺出来”的成分。

一次不需要四条都做。听唱状态一般时，做前两条就够。

## 两小节素材：真正的旋律记忆任务

打开[听觉练习室](../../listening-lab/)，选择原创素材 E2-v1：

1. 听 2–3 次，只拍主拍和有声位置，不唱；
2. 再听一次，只描述轮廓：上行、下行、重复；
3. 停止示范，在留空里独立回唱并录音；
4. 展开答案，先查节奏，再查句首、最高音和句尾；
5. 只修一个错点，不把整段循环到熟背。

已看过答案后再唱对属于复现；之后还要换一条同难度陌生素材，才算检查迁移。

## 从两小节到四小节

固定两小节在两个练习日都能保留主要节奏与三个关键落点，再做 E4-v1。先前两小节、后两小节，最后连接，不靠无限重复整段填记忆。

## 卡住时怎么退

| 现象 | 回退 |
|---|---|
| 拍子对不上 | 只拍手或一个音说节奏 |
| 轮廓也记不住 | 缩成两个音，只判断上/下/相同 |
| 中间音不确定 | 先保留句首、最高、句尾 |
| 跟示范会，停掉就丢 | 增加留空回唱，不换新题 |
| 发声不舒服 | 改成纯听、拍手或休息 |

## 迁移到歌曲和吉他

真实歌曲先截 1–2 秒或两小节，按“节奏 → 轮廓 → 关键音 → 装饰”重做。确认的句首、最高和句尾可以再去吉他上找；反过来，也可以先弹和弦再唱根音、三音或五音。

## 通关

两个练习日都能在**不跟着示范同步唱**的情况下复现固定两小节主要节奏和三个关键落点；再对一条陌生同难度素材使用同样流程。
