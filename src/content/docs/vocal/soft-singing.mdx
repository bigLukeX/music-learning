## 弱唱真正要保留什么

这里的弱唱指：响度降低以后，仍然能听见明确音高，词也没有因为漏气变得模糊。它不是耳语，也不要求完全没有气声。

先有一个轻而清楚的版本，再把少量气声当成表达选择；顺序反过来，很容易把“漏气”误当成“高级弱唱”。

## 卡片怎么选

| 现象 | 优先卡片 |
|---|---|
| 小声一唱就漏气 | vv → u 轻起音 → 轻元音 4拍长音 |
| 中声没问题，但弱声掉音 | mum 中声→弱声 |
| 会弱唱，但句尾总塌 | 轻元音 4拍长音 → wu 4拍渐弱 |
| 想练动态而不是单纯小声 | mum 中弱对照 → wu 渐弱 |

## 动态录音怎么听

手机可能有自动增益，录音里的波形大小不一定等于你真实的响度差。回听顺序建议是：

1. 先听音高是否还清楚；
2. 再听音头有没有一大口气或突然撞出来；
3. 再听句尾是否还能维持；
4. 最后才比较中声和弱声的响度差。

## 迁移到歌词

选 3–5 秒、音区舒适的一句，先中声唱一次，休息，再只缩小一点。若关键词开始听不清，先减小强弱差，不要为了“弱”把声音做成耳语。

## 常见问题与回退

| 问题 | 回退 |
|---|---|
| 弱声先漏气，再出现音高 | 回 vv → u 或一个轻 mum 单音 |
| 每次先撞出大声才能缩小 | 回基础发声页的连续 vv |
| 变弱就低了 | 缩短长音，减小动态差 |
| 渐弱到最后只剩气 | 后两拍只减一点，不追求消失 |
| 文字模糊 | 只练一个词的元音和短辅音 |
| 疼痛、刺激、沙哑或说话费力 | 当天停止发声 |

## 通关

中声→弱声的音高仍清楚；4拍渐弱句尾不明显塌；一条歌词在稍弱版本里关键词仍可懂；下一次保持同条件还能做到，练后说话正常。
