## 小声时要保留什么

这里的弱唱指降低响度后，仍能听见音高和词；不是耳语，也不要求消灭所有气声。气流、振动和声道一起影响听感。“闭合”不能翻译成夹紧喉咙。先用[基础课](../breath-phonation-resonance/)找到舒适起音，再练下面的变化。

身体疲劳但声音正常时可以缩短；嗓音沙哑、疼痛或费力时按[安全页](../safe-practice/)休息。

## W1 · 同音高弱/中对照，约 3 分钟

1. 用琴或[试听起音](../daily-practice/)给一个舒适音，记录音名；60 BPM，以 `mum` 开始，再让中间元音轻轻持续4拍；
2. 休息4拍，然后在**同一音高**唱较弱的4拍，休息4拍；
3. 以上是一对，最多3对。弱声只比自己的中声小一点，不追求最小；
4. 回听每对，先核对音高，再听音头与句尾，最后比较动态。

使用[同一录音距离与模式](../baseline/)。手机自动调节音量可能缩小录音中的强弱差异；以音高、清晰度、舒适感共同判断，不能只看波形大小。`no/gee`等只是[备选读法](../daily-practice/#syllables)，本次先固定mum。

## W2 · 小范围渐弱，约 2–3 分钟

W1可重复后，同一音高用 `wu` 唱4拍：第1–2拍保持中声，第3–4拍稍微减弱；休息4拍，共3轮。每轮后用琴重听目标音。

先只练小幅渐弱；如果变弱时跑调或只剩气流，就把减弱幅度减半。4拍已费力时改2拍声/4拍休息，不延长气息来“练肺活量”。本课不要求把整段持续唱成一口气。

## W3 · 一句歌词，约 3 分钟

选3–5秒、音区舒适的一句：先中声一次，休息15秒，再稍弱一次；最多做3对。辅音短、元音承载时值。回听时不看歌词，检查是否还能听懂关键词；用琴核对句首和句尾。

## 自检与回退

| 现象 | 调整 |
|---|---|
| 弱声先有一大口气，再出现音高 | 回到一个轻mum短音；先找清楚起音再延长 |
| 每次都先撞出大声，随后才能缩小 | 不做渐弱；回基础课的连续vv，再接轻元音 |
| 变弱就低了 | 缩短到2拍、减小动态差；先听参考音再唱 |
| 音高对了，文字模糊 | 只练一个词的元音与短辅音，再接回一句 |
| 听不出“清楚弱声”和漏气差别 | 保存W1的三对录音请教师核对，不以更用力来补 |
| 疼痛、刺激、沙哑或说话费力 | 停止当天发声并休息 |

有意气声可作为表达选择；先有轻而清楚的版本，再比较少量气声版本，听稳定性与句尾是否还能保持。无需把气声当成默认的弱唱动作。

## 关卡

W1三对中的弱声仍有清楚音高；W2的句尾不明显塌；W3弱声关键词可懂，练后说话正常。下一次保持同条件仍能做到，再把弱/中/稍强三级动态用于歌词；“稍强”仍在舒适范围，不以喊叫完成第三级。

播放器可给起音或伴奏，但没有真人动态示范，也不会替你判断内部动作。每次从W1–W3选当前最小任务，不为凑10分钟重复发声。
