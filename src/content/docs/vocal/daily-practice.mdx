## 先判断今天是否适合发声

自然说一句话，再轻哼一个舒适音：

- 与平时相同且没有不适：选择常规或当前需要的短练习；
- 只是身体疲劳，但说话与轻哼都正常：可选轻柔版，或休息；
- 明显沙、低、费力，喉咙疼/刺/灼热，或连续练习后嗓音下降：**今天停止发声并休息**，恢复后再复查；
- 持续异常或其他需要就医的情况：按[安全练习](../safe-practice/)处理。

轻柔版不是异常嗓音的治疗。日常维护也不替代未来的[个人定位](../baseline/)。

## 自动钢琴

默认 `C3` 起音、`E4` 上限只是可调整初值。若 C3 太低，选更舒适起音；若 E4 不舒服，降低上限。**上限是限制，不是必须达到的目标。**

<VocalPracticePlayer />

播放器显示当前计划的实际音域与预计时长。默认 `C3/E4/72 BPM` 时，**学习模式约 11 分 17 秒**，熟悉后切到连续模式约 **10 分 32 秒**；实际最高音都是 **D4**。学习模式在每一种新音型开始时先完整示范一次，第一调给 4 拍准备，后续移调给 2 拍。改变速度或范围会改变时间。它不包含身体检查、额外休息或歌词练习。

播放期间改任何参数（包括速度、器材），旧播放立即停止；确认新计划后按开始重启。停止线不能靠旧序列继续生效。

## 五项设置怎么选

| 控件 | 选择依据 | 何时调整 |
|---|---|---|
| 跟练模式 | 第一次用某套音型选学习；已经熟悉音型才选连续 | 学习模式会先示范新音型，不要求你一按开始就知道旋律 |
| 套餐 | 已会动作选常规；当前只处理一个问题就选专项 | 未学会动作先做对应[基础课](../breath-phonation-resonance/)或手动短练习 |
| 器材 | 有设备且按说明装好才选有瓶 | 没带、未清洁或不确定装法时选无瓶 |
| 舒适起音 | 能小音量轻哼3次，不压低、不抬高 | 起音本身不舒服就改；不为了够高而提高起音 |
| 天花板 | 当天已知能舒适重复的上限 | 任何挤压就降低；不要仅凭播放完成提高它 |
| 速度 | 新音型60 BPM；熟悉后72 | 84只用于已经清楚的灵活性练习 |

设置上限提高而音序列未改变时，播放器会提示。各环节还有固定的移调范围，因此 E4 改到 F4 可能不改变实际最高音。记录实际唱过的音型和最高音，不能把控件值当成高音通关。

你已确认 `G4/A4` 一带偶尔能碰到，但质量和重复性仍待校准；这不能直接决定每天的练习上限。试听只需轻哼一次，不用大声证明能到。

## 音节不熟时先做什么

先听读法示意，再以说话音量模仿两次，最后按参考音跟唱。合成语音只示意读法；钢琴只给音高。两者都不示范真人声乐动作。

## 一次约 20 分钟整体流程

| 环节 | 时间与次数 | 做什么 |
|---|---|---|
| 状态与准备 | 2分钟 | 录10秒自然说话，安静呼吸3轮，确认舒适起音 |
| 常规自动音型 | 以播放器当前预计时长为准 | 默认约10分32秒；半闭合段已经包含在内，不另加3分钟瓶子练习 |
| 安静休息与回听 | 约2分钟 | 停止发声，听刚才最有疑问的一段；只选一个问题 |
| 歌词迁移 | 3–4分钟，最多3遍 | 一句舒适歌词：说节奏→元音→原词，遍间休息约15秒 |
| 结束复查 | 1分钟 | 重说开头那句话，与练前比较 |

默认学习模式下合计约 20–21 分钟；熟悉后切连续模式通常接近原来的 19–20 分钟。范围较窄时会更短；较慢时会更长。预览超出当次可用时间就选短版或手动任务，随时可停，不补做、不追进度条。当天嗓音变差就停止，歌词迁移也不继续。

## 没有合适套餐时：手动三音或单音

如果当前舒适上下限容纳不了套餐，不要为了启动它去压低或抬高声音。用“试听起音”或琴给音后，做[基础课三音短型](../breath-phonation-resonance/)；三音仍不舒服就只做舒适单音 2 拍、休息 4 拍，60 BPM，最多 3 次。即使单音也费力，就停止。

## 有瓶与无瓶

练声瓶只替代半闭合段；其余元音、听唱和歌词任务保留。有瓶与无瓶版播放同一音型，时间相同。

若设备是吸管入水式：按原厂说明设置水位、管深和装配；先有轻而连续的小气泡，再加轻声。若需要猛吹、头晕、咳嗽或喉部不适，立即停止。型号未确认前，本教程不猜厘米数。非入水式不要自行加水；接触口部的零件按说明清洁、晾干，不共用。

无瓶时用唇颤或 `vv`；唇颤不连续就改 `vv`，不要加大气流硬维持。半闭合不是“冒泡越多越有效”，练完仍需能回到开放元音和一句歌词。

## 可选专项：一次只处理一个问题

专项的自动部分在默认设置下约5–6分钟，**以当前显示为准**。加上1分钟安静休息、2–3分钟歌词或指定手动任务、1分钟复查，可组成约8–10分钟的专项时段。状态正常且有余力时才加；也可用专项替换当次常规，不反复叠加套餐。

| 目标 | 可用自动部分 | 仍需手动完成 |
|---|---|---|
| 头声与换区 | 头声专项的半闭合、滑音端点 | [短型录音与回退](../high-notes-and-mix/) |
| 混声连接 | 混声专项的轻起音与琶音 | 同一舒适短句加回歌词；不能靠套餐名确认混声 |
| 元音 | 元音专项 | [同音高元音链核对](../breath-phonation-resonance/)；长音另计拍 |
| 转音 | 五音、琶音与八度音阶 | 先逐音准确，再加速；范围不够就保持较短音型 |
| 弱唱/长音 | 用试听或琴给一个起音 | [4拍长音、弱中动态与渐弱](../soft-singing/)；播放器不自动示范动态 |
| 两/四小节听唱 | [听觉练习室](../../listening-lab/)的原创素材与主音 | 留空回唱、看答案、隔日复测 |
| 英文/歌曲 | 自动部分可不用 | [原创英文两小节](../melody-and-english/)或[选调实验](../song-application/) |

## 七个项目的轮换池

这些是下次练什么的选项，不是七个连续练习日。当前吉他阶段每周选1–2次即可；正式声乐阶段再按[八个训练单元](../first-8-weeks/)安排。

| 选项 | 当次重点 |
|---|---|
| 1 | 常规整体流程 |
| 2 | 舒适换区短练习 |
| 3 | 身体疲劳但声音正常时的轻柔短版 |
| 4 | 元音或轻起音连接 |
| 5 | 弱唱与一句歌词 |
| 6 | 听唱或英文节奏 |
| 7 | 休息、只听录音 |

## 忙碌时的短版

状态检查1分钟 → 轻柔自动音型（学习模式默认约5分33秒，连续模式约5分10秒，以显示为准）→ 舒适歌词最多1分钟 → 复查1分钟，默认合计约8分钟。若这仍太长，只做手动三音加复查。声音异常选择休息，不能通过缩短套餐继续唱。

## 最小记录

```text
日期；维护/正式单元；套餐或手动任务ID：
器材；起音；设置上限；实际最高音；BPM：
自动预计时间；实际停止位置：
练前/练后说话：正常/异常
短句接近次数：__/3；下一次只改一件事：
```

播放器不监听、不评分。出现疼痛、刺激、沙哑、说话费力，或同一位置连续两次变差时停止当天发声；按[安全页](../safe-practice/)休息和复查。
