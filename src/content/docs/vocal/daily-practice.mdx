<details>
<summary>今天这套练什么？</summary>

默认顺序已经排好：闭嘴轻哼 → 轻声“马姆” → 同一句稳稳唱三遍 → 小声、正常、小声 → 记住旋律再回唱。先用舒适的中音完成动作，不测最高音。

每项先留至少8秒看提示，完整听一次参考音，看到倒数结束和“现在唱”再开口。每次换音型、重来或进入下一项都会重新准备；上一项结束后停住，休息多久由你决定。

页面大字告诉你现在发什么声音，下面的字会随音轨逐个亮起。暂停以后点继续，会先回到这一句的准备段，不从半个音中间突然接上。

总时长按实际音轨计算，显示在开始按钮上方；手动休息另计。做完默认流程就可以结束，完整练习库不是当天任务清单。

<details>
<summary>有练声瓶时怎么用</summary>

默认流程不需要器材。选择半闭合单条练习时，可在设置里选择已经按原厂说明装好的练声瓶；无瓶则使用有声 v。唇颤已熟悉者也可替代，不靠猛吹维持声音。

设备型号未确认前，只遵循原厂水位、管深和装配说明；不使用通用厘米数。头晕、咳嗽、疼痛或发声费力时停止。
</details>

<details>
<summary>手机音量与播放方式</summary>

这版把参考音、倒数和休息编入同一条媒体音轨，用真正的音频播放器播放。画面读取音轨时间，不再用多个定时器分别驱动琴声和文字。在支持 Audio Session API 的浏览器上额外请求 playback 模式；不申请麦克风。

点“先试声音”，在播放过程中用手机音量键调媒体音量；仍然偏小时再检查蓝牙输出和“音轨响度”。应用内浏览器行为可能不同，不能仅凭电脑测试保证每台手机一致。

技术依据：[W3C Audio Session](https://www.w3.org/TR/audio-session/)；[WebKit 关于网页音频与静音开关的说明](https://bugs.webkit.org/show_bug.cgi?id=237322)。
</details>
