## 这页其实包含三个不同问题

- **头声入口：** 高处能不能变轻，而不是只能继续把胸声做大；
- **换区连接：** 上去和回来时是否能保持连续，不突然断、翻或砸回来；
- **混声协调：** 在比纯头声更有实体感时，仍能保持可重复、不过度用力。

它们相关，但不是一个按钮。某个音节唱上去一次，也不能单凭这一遍就宣布“已经混声”。

## 卡片怎么选

| 现象 | 优先卡片 |
|---|---|
| 一到换区就明显变大声 | 半闭合换区五音 → 轻 wu 三音 |
| 某个位置偶尔能唱到，但第二遍就变样 | **固定调 ×3 · 换声区稳定** |
| wu / mum 很顺，一打开到“啊”就挤 | **wu → 啊 · 闭到开元音** |
| 高点能碰到，但进去和下来不稳定 | **进入 → 停留 → 离开高点** |
| 能滑过去，但分明音高不稳 | 轻 wu 三音 → mum 琶音 |
| 上去还行，回来像砸回胸声 | ng → u 头声落回 → wu 五度滑音 |
| mum 可以，但换成更清楚辅音就挤 | gug 换区五音，先降低范围 |
| 今天只想轻量维护 | 半闭合换区五音 + wu 五度滑音 |

## 练的时候只听三个东西

1. **最高处有没有突然变响。** 如果只有加音量才能完成，这一调就已经超过今天的可用范围；
2. **下巴和脖子有没有跟着帮忙。** 抬下巴、伸脖子、咬紧下颌都不是本条要练的动作；
3. **回来以后是否还能恢复。** 上去一次成功但回来失控，不算稳定连接。

## 为什么卡片会自动经过几个调

同一动作经过几个相邻音高，可以帮助你观察什么时候开始失稳。但自动移调只是练习方法，不是让你冲天花板。任何一调出现明显挤压、突然变响或声音质量下降，都可以直接停止这条，下次降低上限。

## 针对当前主要弱项的三条优先卡

### 固定调 ×3 · 换声区稳定

这条**故意不自动升调**。把“舒适起音”调到今天想复测的位置，三遍都留在同一个调。它回答的是“这个位置能不能连续稳定”，而不是“今天最高碰到哪里”。

### wu → 啊 · 闭到开元音

三遍分别从全程 wu，过渡到部分打开，再到全程轻“啊”。如果第三遍明显失控，说明闭元音里的协调还没有真正迁到更开放的歌词元音；不要靠更大声把它顶过去。

### 进入 → 停留 → 离开高点

`3–4–5–5–4–3` 会让最高点待两个拍子。真实歌曲里的高音常有“进去—待住—离开”的上下文，这条比只碰一下最高音更接近实际使用。

## 从专项回到歌词

专项顺了以后，再到[歌曲落地](../song-application/)选“难句先元音后原词”或“一句歌词四层迁移”。不要在同一轮里同时改音高、音量、元音和表情；一次只把一个协调放回真实文字。

## 常见问题与回退

| 问题 | 回退 |
|---|---|
| 高处突然喊起来 | 降 1–2 个半音，回半闭合或轻 wu |
| 变轻后只剩气流 | 回基础页的 vv → 元音或 mum 三音 |
| 滑音顺但分明音不准 | 暂停滑音，用三音或琶音逐音唱清楚 |
| gug 让舌根和喉咙都紧 | 改回 mum，不用更大力的 g |
| 专项能唱，歌词一回来就挤 | 先只唱歌词元音，再加辅音 |
| 疼痛、刺激、沙哑或说话费力 | 当天停止发声 |

## 通关

同一组短卡在两个练习日都能保持：高处不突然放大、上下连接正常、练后说话正常；再选一句最高音不超过该范围的歌词，能用同样协调连续复现。记录**实际唱过的最高音**，不把控件上限当成绩。
