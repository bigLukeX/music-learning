## 先理解要观察什么

音高上升时，发声与元音往往需要调整。“减重”在本课是**听起来不越来越喊、做起来不追加力量**的提示；“混声”是常见教学名称，不是单一按钮，也不能单凭某个音节或一次高音确认内部机制。声源、声道与声区的基本关系可参考 [UNSW 的声音实验](https://phys.unsw.edu.au/jw/voice.html)。

本课先修：[基础三音短型](../breath-phonation-resonance/)能舒适完成三次，练后说话正常。今天声音异常则按[安全页](../safe-practice/)休息。`G4/A4` 是个人待定位关注区，不是本练习终点。

## 练习 H1 · 三音连接，约 3–4 分钟

1. 用琴或[播放器试听](../daily-practice/)选当天舒适起音，记录音名。`60 BPM`，用 `wu`（轻“呜”）唱 `1–2–3–2–1`，每音一拍；
2. 唱一遍后休息5秒，做3遍。先保持同一调，不自动上移；
3. 回放录音：听每个音是否到位，最高处是否突然更响，回落后是否恢复同样清楚；
4. 本次只用一个起音位置。在两个练习日都舒服且接近后，下次才考虑升一个半音；首次变差就停止上移。

例如 C 起音的音名是 C–D–E–D–C，选择舒适八度。音节动作见[字典](../daily-practice/#syllables)。

## 练习 H2 · 连接与明确音高分开检查

在 H1 已成功的同一范围内，用 `wu` 从1平顺滑到3再回1，分别用2拍上行、2拍下行；休息4拍，做3轮。然后唱一次 H1 的分明五个音，避免把“能滑过去”误当作能停在目标音。

若想用播放器的 `1–5–1` 滑音端点，先确认这整个五度范围当天都舒适；它比 H2 宽，不是必做升级。钢琴是离散端点，你唱的是连续连接，不能用钢琴音色推断唱法。

## 练习 H3 · 用一句歌词验证，约 3 分钟

挑一条3–5秒、最高音不超过已成功短型的歌词。说节奏一次 → 只唱元音两次 → 加回原词两次，次间休息10–15秒。元音承担长音，辅音短而清楚；先不追求原唱音色。

可尝试稍小的口型或更顺的元音，但不能把所有字强行唱成“呜”。一次只改一个词，录音检查可懂度；下巴、舌根更紧就回原来的舒适读法。

## 回听时怎么区分问题

| 听到/感觉到什么 | 下一步 |
|---|---|
| 最高音突然比其余音响很多，或抬下巴才完成 | 停止上移；下次降1–2个半音，只做H1 |
| 变轻以后只剩气流，音高不清楚 | 回到舒适单音 `mum` 或 `vv→u`，不加气、不夹喉 |
| 滑音连续，但分明音高不准 | 暂停滑音，用琴给每个目标音，先听再唱 |
| 音型可以，原词就挤 | 缩成一个词，先只唱元音；不重唱整段 |
| 三次差异很大却听不出原因 | 保留三段录音请教师校准，保持当前范围 |
| 疼痛、刺激、沙哑或说话费力 | 当天停止发声并休息，按安全页复查 |

## 关卡

同一起音与速度下，H1三次接近、回到低音后仍正常；H3的一条歌词能连续三次舒适复现；下一次同条件复测也成立。记录**实际最高音**与短句版本。没有通过只重复对应的小任务，不因为播放器能播更高就升调。
