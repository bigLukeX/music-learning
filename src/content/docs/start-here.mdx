## 每次学习只经过四步

1. **看当前任务：** 只读与今天练习有关的段落。
2. **慢速执行：** 用能控制的速度完成，不用速度掩盖问题。
3. **留下证据：** 录音、视频、节拍器速度、TAB、音名记录或文字复盘至少一个。
4. **按标准判断：** 写“通过 / 部分 / 未通过”，再决定下一步。

## 页面上的三种状态

- **当前：** 现在可以执行，例如吉他定位练习 A。
- **路线：** 内容已写好，但需要等前置能力通过。
- **参考：** 用于解释原理，不能代替乐器或声音练习。

## 个人资料与公开网页分开

教程正文可以发布为网页；个人录音、嗓音状态、练习日志和未经筛选的进度默认不发布。仓库已忽略常见音视频文件与 `recordings/`、`private-progress/` 目录。

公开部署之前要再检查一次：正文里是否出现真实姓名、联系方式、私密录音链接或不希望公开的学习记录。
