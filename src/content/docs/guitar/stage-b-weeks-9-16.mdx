## 阶段结果

第 16 训练周结束时要能：

- 在两个相邻 CAGED 区域找到大/小三和弦，并指出根音、三音、五音；
- 认识大七、属七、小七、半减七的结构与基本听感；
- 用慢速琶音把和弦音弹清楚，而不是只背整块指型；
- 把一个进行写成级数，并说明最基本的稳定/离开/趋向；
- 口数、拍手、上琴各完成一个三连音型和一个连音线型；
- 在一个把位弹大/小五声音阶与自然大/小调，并知道根音位置；
- 给同一进行做开放和弦、移动和弦与琶音三个版本，再加一个短旋律回答。
- 同一和弦独立给出三种实际 voicing，报出各自最低音和和弦构成音；改变拨弦次序不算多一种 voicing。

本页的“通过”都是**项目入口任务通过**。块 2–4 的其他把位、移调、琶音变体与节奏组合，和块 5–6 的后续练习，一并保留余量；不把八个训练周写成原课程已全部完成。

`Song A` 的内容不必覆盖每个新主题。它只有 Em/Am 时，歌曲任务仍按这两个和弦练；大三和弦对照另取 C/G，大小对照另取 C/Am，四和弦任务另用[已有指法](../chords-and-transitions/)的 `C–Am–Fmaj7–G`，每小节一和弦、4/4、舒适 BPM，练 8 小节。它们是独立短练习，不替换整合曲；未熟的手型先逐个建立，再接成循环。

## 每个训练周固定六次循环

默认每个自然周练三次：A 周完成 D1–D3，B 周完成 D4–D6。D1–D6 是练习顺序，不是星期几；漏练时直接顺延，不补课。

| 练习 | 任务 |
|---|---|
| D1 | 看本训练周第一个主题，做最小动作版本 |
| D2 | 不看课件复现，并在两个调或两个把位测试 |
| D3 | 看第二个主题，把指板、和声和琶音接起来 |
| D4 | 耳朵/Voice Leading/节奏迁移 |
| D5 | 放进当前歌曲或四和弦进行 |
| D6 | 录音与通关；通过后进入下一训练周 |

普通练习仍按 `准备 5 + 节奏 10 + 技术/琶音 8 + 指板/和声 7 + 耳朵 7 + 歌曲 8`。需要看课的练习使用 `看课 10 + 准备 4 + 节奏 8 + 技术 6 + 指板/和声 5 + 耳朵 5 + 歌曲 7`。

## 第 9 训练周 · 大三和弦、CAGED 入口与大三和弦琶音

课件：按上表第 9 周定位。指板先选 C 与相邻 A 形，只弹舒适的部分和弦或逐音结构音；先核对根音位置，再移调。

| 练习 | 照做 |
|---|---|
| D1 | 看大三和弦/CAGED；只选当前最实用的两个相邻形状；每个形状圈根/3/5；节奏保持前阶段最稳的八分型 |
| D2 | 不看图重建两个形状；在 C、G 两调各找一次；弹每个和弦的 `1-3-5-3`，先唱再弹 |
| D3 | 看大三和弦构成与琶音 20；一个把位上行/下行；每个音报音级，不追 12 调 |
| D4 | 听大三和弦后唱根音与三音；两个和弦用最近位置切换；记录最高声部上/下/不动 |
| D5 | 从 Song A 选两个大和弦做开放/移动对照；没有两个大和弦时独立用 C/G，每小节换一次共 8 小节，Song A 不改 |
| D6 | 两个形状不看图；根/3/5 指认；一个大三琶音；8 小节进行录音 |

过线：不要求五形全背；要求两个相邻区域不迷失根音，并能把形状拆成和弦音。

## 第 10 训练周 · Voicing、小三和弦与小三和弦琶音

课件：按上表第 10 周定位。大调音级与当前和弦构成音的参照不同，先用[指板页双栏例子](../fretboard/)检查一次。

| 练习 | 照做 |
|---|---|
| D1 | 看 Voicing 与小三和弦；比较同根大/小和弦，只改变三音；听颜色变化 |
| D2 | 两个相邻区域各弹大/小对照；随机指出哪个音把属性从大变小 |
| D3 | 看小三琶音与大调顺阶三和弦入口；一个把位弹 `1-b3-5-b3`；只构建 C 调七个三和弦 |
| D4 | 听一个和弦判断大/小；独立在 C–Am–Fmaj7–G 标 I–vi–IVmaj7–V，先按根音定位；最高音尽量走最近距离 |
| D5 | Song A 若同时有大/小和弦就各选一个；否则独立用 C/Am 做开放版/移动版/分解版，每版 8 小节，Song A 不改 |
| D6 | 大/小三和弦对照、C 调顺阶三和弦口述、两个琶音和歌曲段落各录一次 |

过线：能指出三音怎样决定大小属性，并把这个区别听到、说出、弹出。

## 第 11 训练周 · 七和弦家族与琶音

课件：按上表第 11 周定位，先看结构再选同根音的一形对照，不一次增加五形与 12 调。

:::note[课程量控制]
一个训练周内只要求把大七、属七、小七、半减七的结构和一个实用形状接起来。其他和弦类型、原课多形/移调及视频内容列为余项，放到第 12 周及后续关卡继续；本周过线不等于“第一章已完成”。
:::

| 练习 | 照做 |
|---|---|
| D1 | 看大七/属七；从大三加入 `7` 或 `b7`；同根三连对照；只练一个区域 |
| D2 | 看小七/半减七；从小三加入 `b7`，再把 `5` 降为 `b5`；同根对照 |
| D3 | 看琶音 22–25；每类只选一个最可控形状，每个音报音级，速度统一用最慢一类 |
| D4 | 先判断基础三和弦为大三/小三/减三，再比较七音；半减七是减三和弦加小七度。用自弹录音或听觉实验室核验，未辨出则退回同根两类对照 |
| D5 | 当前进行允许时替换一个七和弦并检查旋律碰撞；不合适就撤回 |
| D6 | 四类结构口述、四个慢速琶音与一个 8 小节应用录音 |

过线：能从 `1/3/5/7` 的变化推导四类七和弦，慢速下目标音清楚；不要求五形和 12 调。

核对表：大七 `1 3 5 7`，属七 `1 3 5 b7`，小七 `1 b3 5 b7`，半减七 `1 b3 b5 b7`。花 5 分钟先录同根的小七/半减七各 3 次，随机回放，听五音改变；至少分对 4/6，下一次换一组。此听辨是补强记录，不能用“暗一点”代替构成音说明。

## 第 12 训练周 · Voice Leading、调内进行与和声功能

课件：按上表第 12 周定位，琶音 20–25 复习。原件已有歌曲应用；本次选一个短段落，说明自己选了哪些实际声部，不复制整首谱。

| 练习 | 照做 |
|---|---|
| D1 | 看 Voice Leading；同一进行用最近移动连接两个区域，不增加新和弦 |
| D2 | 用和声页三种 C voicing 作 6 分钟自测，分别报低音/根音；再标进行的最高音，录开放版与高把版 |
| D3 | 在一个大调写 `I ii iii IV V vi vii°`；给 `I/IV/V` 标最基本的主/下属/属功能 |
| D4 | 听 Bass movement 与顶部旋律，分开记录；不把两个声部混成和弦猜测 |
| D5 | 给 `Song A` 一个段落写字母、级数、根音方向；不确定处标待验证 |
| D6 | 同一和弦三种实际 voicing；同一进行两个区域、顶部线条说明、级数/功能表与录音 |

过线：三种排列能重建并说明低音，选择有声音移动理由；能把一个实际进行从字母和弦转换成级数，并区分听到与推断。第三种排列未稳就继续本周，不把同一形分解成琶音算作第三种。

## 第 13 训练周 · 三连音、连音线与综合节奏

课件：按上表第 13 周定位；本训练周不新增和弦种类。原课有多个组合，本轮只取下表指定的最低版本，其他组合继续登记。

| 练习 | 照做 |
|---|---|
| D1 | 看三连音重音；口数稳定口令；重音放第一、第二、第三下各 4 小节 |
| D2 | 看三连音组合；只选一个组合，拍手→闷弦→单音琶音 |
| D3 | 看连音线；只选一个跨拍延长，声音延长时手部细分继续 |
| D4 | 从八分、十六分、三连音中只选两种混合；一个和弦→两个和弦 |
| D5 | 歌曲适合时迁移；不适合就用鼓机/和弦循环，不硬改歌曲风格 |
| D6 | 一个三连音型和一个连音线型：口数、拍手、闷弦、上琴各一遍 |

过线：三连音三等分；声音延长不吞下一拍；混合节奏中仍能指出主拍。

## 第 14 训练周 · 大/小五声音阶与落点

课件：按上表第 14 周定位，只取“大/小五声音阶各一个把位 + 一个三音组 + 一个跳音”。对应组头重音能稳定后，才逐步补原课重音移位。

| 练习 | 照做 |
|---|---|
| D1 | 看大调五声音阶；一个把位慢速上/下；每次停在 `1/3/5` 并唱出落点 |
| D2 | 同一把位做最简单三音组；重音只固定在组头；不因手熟就加速 |
| D3 | 看小调五声音阶；一个把位慢速上/下；标 `1/b3/4/5/b7` |
| D4 | 小调五声音阶做最简单跳音；先唱目标音再跨弦；检查误碰 |
| D5 | C 大调五声配 C 大三和弦，A 小调五声配 Am；先确认音阶根音，再各做 2 小节问答，句尾落各自和弦音，Song A 不必另含大和弦 |
| D6 | 大/小五声音阶各一个把位、一个三音组、一个跳音和 4 小节短句录音 |

过线：知道根音位置，能在慢速下均匀完成一个把位，并让短句落到目标音；不要求五个把位。

## 第 15 训练周 · 自然大/小调与相邻把位入口

课件：按上表第 15 周定位。原课多形串联先只跨一个相邻边界，下一次能返回根音再延长；未核对的 App 泛称不作为本周必须找齐的前提。

| 练习 | 照做 |
|---|---|
| D1 | 看自然大调；从大调五声补入 `4/7`；一个把位上/下并停在 `1/3/5/7` |
| D2 | 做最简单三音组或三度跳音；每组只观察均匀、重音和目标弦 |
| D3 | 看自然小调；从小调五声补入 `2/b6`；一个把位上/下并报音级 |
| D4 | 用一个共同根音比较五声与七声音阶；只听新增两个音造成的差别 |
| D5 | 找相邻把位最近的一个连接点；用 2–4 小节短句跨过边界再返回 |
| D6 | 大/小调各一个把位、一个连接点、一个歌曲或耳扒应用录音 |

过线：不只会上下跑；能按指定音级结束短句，并从一个把位跨到相邻区域后回到根音。

## 第 16 训练周 · 阶段 B 整合关卡

| 练习 | 照做 | 交付 |
|---|---|---|
| D1 | 复测大/小三和弦两个区域；同一和弦三种 voicing，逐一报实际音与低音 | 指板视频 + 三种排列记录 |
| D2 | 复测四类七和弦结构与一个可控形状 | 和弦表 + 音频 |
| D3 | 琶音 20–25 各选一个最实用形状；不追 12 调 | 慢速琶音串联 |
| D4 | 一个进行写字母、级数、功能、Bass 与顶部运动 | 分析页 |
| D5 | 大/小五声音阶与自然大/小调各做一个短句，句尾落目标音 | 四个短句 |
| D6 | `Song A` 同一段各录开放和弦、移动和弦、琶音 8 小节；再选最稳一版整曲一遍到底；三种 voicing 另核验 | 三个短版本 + 完整录音 + 三种排列证据 + 原课余量 |

进入后续关卡前，至少满足：两个相邻区域不迷失根音；四类七和弦能从结构推导；同一和弦三种 voicing 能不看表重建并说明低音；一个进行能写级数；一个三连音型和一个连音线型不丢主拍；大/小五声与自然大/小调各一个把位能落到目标音；课程内容已迁移到歌曲和短扒带。每项用本页 D6 的最低版本，不要求完整五形/12 调一次全会。

没通过只重复相关训练周，不把第 9–16 周全部重来。通过后进入[第 16 周后的关卡](../post-16-gates/)；块 **2–6** 的全部未完组合、把位、移调和应用都写入余量表，与后续扒歌并行，不能只登记块 5–6。
