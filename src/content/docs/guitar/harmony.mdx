## 先从音程构建和弦

三和弦由根音、三音和五音组成。大三和弦的三音距根音为大三度，小三和弦则为小三度；五音通常是纯五度。吉他形状只是这些音在指板上的一种排列。

## 大调调内三和弦

把大调七个音依次作为根音、隔一个音叠三度，会得到：

```text
I 大　ii 小　iii 小　IV 大　V 大　vi 小　vii° 减
```

先用具体调性验证，例如 C 大调，再把级数概念迁移到 G、D、A 等吉他常用调。

## 和声功能

- **主功能：** 提供归属与稳定，典型是 I、vi。
- **下属功能：** 把音乐带离主和弦，典型是 ii、IV。
- **属功能：** 制造回到主和弦的方向，典型是 V、vii°。

功能不是给每个和弦贴永久标签，而是描述具体语境里的方向。

## Voicing 与转位

**Voicing** 是这些音在不同八度、声部中的实际排列；**转位**只看实际最低音是根音、三音还是五音。例如 C 和弦始终由 C/E/G 组成；C/E 表示低音 E、根音仍为 C。改变拨弦先后做成琶音，不一定改变 voicing。

同一个和弦可以用开放和弦、横按、triad、小部分和弦、开放弦色彩或高把位排列。选择时考虑：

1. 当前旋律最高音；
2. 与前后和弦的最短移动；
3. 是否与 Bass 或另一把吉他重叠；
4. 音色要开放、紧密、厚还是轻。

### 原创例子：同一个 C，三种排列

只拨 3/2/1 弦；表中三项依次为这三根弦的品号。先逐音弹，再一起发声，不要求一次横按六根弦。

| 写法 | 3/2/1 弦品号 | 从低到高的音 | 最低音与转位 |
|---|---|---|---|
| C | `5 / 5 / 3` | C4 E4 G4 | C，原位 |
| C/E | `9 / 8 / 8` | E4 G4 C5 | E，第一转位 |
| C/G | `12 / 13 / 12` | G4 C5 E5 | G，第二转位 |

用 6 分钟：每形逐音核对 1 分钟；`60 BPM` 每形保持 4 拍，三形顺序弹两轮；最后随机点一种，说最低音和实际音名后重建。连续两次练习都能不看表完成 3/3、没有明显邻弦噪音，才记“三种 voicing”通过。高把位难够时先分开拨音、降低压力；仍不舒适，保留待补，不以重复同一形的琶音替代第三种。

最近移动的小例子：从上表 `C：5/5/3` 到 `F/C：5/6/5`。3 弦的 C 不动，另两声部 E→F、G→A；第二个和弦的低音仍是 C，根音换成 F。每小节一形，`60 BPM` 连续 8 小节，先听各声部移动，再比较整把开放和弦的跳动。

## 色彩和弦

在稳定理解三和弦后，再进入 `sus2`、`sus4`、`add9`、slash chord、七和弦、借用和弦与副属和弦。每学一个都要放进真实进行比较，不把名称当作完成。

先做一个区别：以 C 为根音，`Csus2 = C D G`、`Csus4 = C F G` 用 2 或 4 替代三音；`Cadd9 = C E G D` 保留三音再添 D；`C/E` 则仍是 C 大三和弦，只指定低音 E。它们不是同一个“省力手型”的不同名称。

《指板》主题 25–26，PDF 36–37 页已有色彩图示；更多和弦种类与延伸在主题 24–31，PDF 35–51 页。第 16 周后按[后续关卡](../post-16-gates/)选择一个原课主题，先做 4 小节原版/4 小节替换版，检查旋律与低音；合适才保留。借用与副属先接[乐理和声页](../../theory/chords-and-harmony/)，不用在前 8 周提前刷完。

## 关卡
