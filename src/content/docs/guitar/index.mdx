## 能力树

```text
节奏 ── 和弦 ── 技术
  │       │       │
指板 ── 音阶 ── 乐理
  │       │       │
听力 ── 扒歌 ── 表达
            │
      ┌─────┴─────┐
   民谣/指弹     电吉他/音色
      └─────┬─────┘
        即兴 / 编曲
```

节奏、耳朵和指板不是学完一门才开始下一门，而是从第一天并行；每个阶段只改变比重。歌曲负责把这些能力重新合在一起。

## 阶段 0–9

| 阶段 | 核心问题 | 通关证据 |
|---|---|---|
| 0 基本操作 | 能否独立准备并完成一首歌 | 调音、8 小节不断拍、完整歌曲 |
| 1 节奏吉他 | 能否从“按对”变成“像音乐” | 细分、重音、空拍、groove |
| 2 技术与旋律 | 单音动作和消音是否可控 | 三个 riff，其中一个自己耳扒 |
| 3 指板 | 是否知道自己弹的是什么音 | 6/5 弦、八度、音级与五形 |
| 4 和声 | 是否理解和弦为什么这样走 | 调内和弦、功能、三种 voicing |
| 5 耳朵与扒歌 | 能否脱离现成谱面 | 结构、根音、节奏、旋律记录 |
| 6A 木吉他 | 能否做完整弹唱/独奏织体 | PIMA、低音、旋律与和弦协调 |
| 6B 电吉他 | 能否控制该响和不该响的弦 | 消音、riff、音色和动态 |
| 7 即兴 | 能否围绕和弦说出句子 | 目标音、motif、呼应与留白 |
| 8 编曲 | 声部能否互相避让 | 同一进行的两层互补声部 |
| 9 高阶整合 | 能否听、找、理解并改编 | 完整 transcription 与 arrangement |

## 原一年路线：按训练量而非截止日期理解

原来的月份按每周约 5–6 次练习估算。当前默认每个自然周练 3 次，所以日历时间预计约为原来的两倍；能力顺序不变，按关卡推进。

- **0–2 个月训练量：** 基本功。八分/十六分、切分、消音、6/5 弦音名、每个训练周一个短耳扒、一首完整歌曲。
- **2–4 个月训练量：** 指板与和声。大调、音程、三和弦、CAGED、五声音阶、triad 转位。
- **4–8 个月训练量：** 系统扒歌。根音 → 和弦 → 节奏 → riff/旋律 → 装饰 → 音色/动态。
- **8–12 个月训练量：** 自己做吉他声部。为同一进行制作民谣、indie/emo 与 shoegaze 等不同织体。

## 课程地图

| 课程 | 作用 | 何时使用 |
|---|---|---|
| [持琴、调音与记谱](./foundations-and-setup/) | 建立每次练习可重复的准备和基本声音 | 阶段 0 或基础有缺口时 |
| [定位练习 A](./positioning-a/) | 测完整歌曲、节奏与错误恢复 | 当前任务 |
| [定位练习 B](./positioning-b/) | 测技术、指板与耳朵，并按缺口分流 | A 的结果记录后，允许含尚不会/未测 |
| [开放和弦与切换](./chords-and-transitions/) | 让和弦进入持续右手和歌曲 | 阶段 0–1 |
| [前 8 训练周](./first-8-weeks/) | 每周 3 练；一个训练周跨两个自然周 | 定位 A/B 完成后 |
| [第 9–16 训练周](./stage-b-weeks-9-16/) | 继续六次一关，学习和弦、和声、琶音、进阶节奏与音阶 | 阶段 A 通过后 |
| [第 16 周后的关卡](./post-16-gates/) | 收束课程余项，接扒歌、分支、即兴与编曲 | 阶段 B 入口任务通过后 |
| [电吉他音色](./tone-and-signal-chain/) | 从干声、增益到效果与声部 | 消音和节奏可控后 |

## 课程资源如何使用

NeoMusic 中阶课程作为主资源，但不按“看完视频”计算进度。每课执行四步：复述课程问题、慢速完成动作、迁移到歌曲或短片段、记录证据。具体映射保留在项目文档中，正式开练时按 App 中实际章节核对。

当前下一步仍是 [定位练习 A](./positioning-a/)，新增课程没有改变个人进度。
