效果器能放大细节，也会放大杂音。当前若节奏、消音和音长尚不稳定，先把本页当作参考，不用购买设备替代基本功。
:::

## 信号经过什么

最小链路是：琴弦振动 → 拾音器转成电信号 → 线材/效果 → 放大器前级 → 功率放大与扬声器 → 空间与麦克风。每一环都可能改变频率、动态、失真和噪声，因此“某块效果器的声音”从来不是孤立的。

## 第一步永远是干声基线

关闭额外效果，用中等音量完成：单音、和弦、静音、音量旋钮从小到大。记录拨弦轻重、拾音器选择和琴上音量。若干声已经有邻弦乱响，高增益只会让问题更明显。

## Gain、音量与动态

Gain 控制信号进入失真或压缩区域的程度，不等于最终听到的音量。增益升高会增加延音和谐波，也会压缩强弱差异。练习同一 riff 的低、中、高三档增益，判断在哪一档仍能听见重音和休止。

## EQ 是给声部找位置

- 低频过多会与 Bass、底鼓和低音吉他弦拥挤；
- 中频常决定吉他是否能在乐队中被听见；
- 高频影响拨片、清晰度和刺耳感。

不要只在独奏时追求“厚”。在伴奏中略薄、略中频突出的音色，可能比房间里单独听更合适。

## 效果家族

| 类别 | 主要改变 | 先问的问题 |
|---|---|---|
| Compressor | 动态范围、起音与延音 | 是否把强弱全部压平 |
| Overdrive / Distortion / Fuzz | 削波、谐波与压缩 | 颗粒是否服务风格，杂音是否可控 |
| Chorus / Phaser / Flanger | 时间/相位调制 | 是否模糊节奏与音高中心 |
| Delay | 重复与空间节奏 | 重复是否与拍子对齐或有意错开 |
| Reverb | 反射与空间尾音 | 尾音是否吞掉换和弦和休止 |

## 一次只改变一个变量

录同一段 8 小节素材：第一遍干声；第二遍只加一种效果；第三遍只调整一个参数。标记效果打开后，重音、静音、和弦清晰度和声部位置发生了什么。无法用一句话解释作用的效果，暂时关闭。

## 三种风格实验

1. **Rock：**中等增益 + 短空间，检查 power chord 停顿；
2. **Indie / emo：**较清晰干声 + 轻 modulation 或 delay，让顶部旋律保留；
3. **Shoegaze：**失真与长空间形成织体，但先录无效果结构版，再逐层增加。

## 通关

- 能区分 gain 与最终音量；
- 同一 riff 在三档增益下仍保持节奏；
- 能用 EQ 解释“给人声/Bass 留位置”；
- 每个已启用效果都有明确声部作用；
- 关闭效果后，演奏本身仍然成立。
