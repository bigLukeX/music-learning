## 歌曲页解决什么

歌曲不是路线之外的“奖励”，而是把节奏、耳朵、和声、技术和表达重新合起来的场所。每首歌都要回答：现在用它训练什么、最低可完成版本是什么、怎样证明比上次更稳定。

## 统一结构

- 训练目的；
- 版本与来源；
- 调性、速度与拍号，并标注证据；
- 段落结构；
- 根音运动与和声骨架；
- 人声音域、换区与语言难点；
- 吉他最小可演出版本；
- 降调、局部降八度、改旋律或音色备选；
- 分段练习、通关标准与录音复盘。

## 核心课程

1. [版本锁定与证据](./evidence-and-versioning/)：确保所有结论能回到同一录音；
2. [完整工作流](./workflow/)：结构、根音、和声、节奏、旋律到演出版本；
3. [扒歌实验室](./transcription-lab/)：六层拆分与一小时模板；
4. [一把吉他与人声编配](./arrangement-lab/)：骨架版、段落版、个性版；
5. [录音与复盘](./recording-review/)：用相同条件和单一变量迭代。

先完成[原创八小节完整案例](./worked-example/)：有固定音源、分声部、时间点、和声与两版编配答案。具体歌曲页是这些方法的练习场。未经目标录音验证的数据继续标为待验证，不为追求页面“完整”而编造精确调性、速度、音域或和弦。

## 完整示范与真实歌曲项目

四首真实歌曲已补来源入口与首轮任务；未完成听证的数据仍标待验证，不把任务页冒充逐曲分析答案。

| 歌曲 | 主要用途 |
|---|---|
| [Don't Look Back in Anger](./dont-look-back-in-anger/) | 稳定摇滚弹唱、主歌减重、高区与英文重音 |
| [Falling Slowly](./falling-slowly/) | 选调、动态、持续高音的替代方案 |
| [Where We've Been](./where-weve-been/) | 大小和弦色彩、段落与一把吉他简化编配 |
| [When You Sleep](./when-you-sleep/)（Friko 版本） | 翻唱版本复核、多层吉他声部取舍 |

## 版权边界

页面不保存完整歌词、完整未授权 TAB 或整首逐音转录。教学只记录必要的短片段、自写分析、演奏提示和合法来源链接。
