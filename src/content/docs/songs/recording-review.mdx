---

## 基线录音不剪辑

第一次录音的目标是暴露真实状态，因此从第一拍到最后一拍不中断、不回头。设备不必高级，但位置、距离、调性和伴奏版本要记录，之后才有可比性。

## 复盘分三遍

### 第一遍 · 只听音乐是否继续

不看视频、不暂停。判断结构、拍子、段落方向和错误恢复。错一个音但音乐继续，与因小错停拍是不同问题。

### 第二遍 · 分轨注意力

分别只听：吉他右手、人声音高/语言、段落动态、杂音与音色。一次只观察一条线，避免写“整体不好”这种不可执行结论。

### 第三遍 · 锁定时间点

只选最影响音乐的 1–3 个时间点，写清发生了什么、可能原因和下一次测试。不要制作一张十几项批评清单。

## 问题要能转成实验

```text
模糊问题：副歌唱不好。
可测问题：01:42 进入副歌时，右手停半拍，人声第一个长音同时偏低。
下一次实验：先以原速 80% 连接前后两句，只要求右手继续；通过后再单独处理长音。
```

## 版本命名

```text
YYYY-MM-DD_歌曲_版本_实际调_BPM_目标
```

例如目标可以是 `baseline`、`rhythm`、`vocal`、`full-take`。个人录音默认放在 Git 忽略的本地目录，不直接进入公开教程。

## 通过标准

一首歌不是因为录出“最好的一遍”就完成。至少在两个不同日期满足：结构完整、主要节奏稳定、核心难句有可靠方案、错误后继续、结束后身体状态正常。表演级版本还要加入记忆、设备与现场压力测试。

## 周复盘模板

```text
本周录音版本：
与上次保持相同的条件：
结构与节奏证据：
吉他唯一主要问题：
人声唯一主要问题：
动态/编配证据：
已经稳定、不再反复修改的内容：
下一版只改变：
状态：通过 / 部分 / 未通过
```

## 通关

- 录音有明确版本、调性和目标；
- 至少完成一次不剪辑全曲或完整段落；
- 复盘包含精确时间点；
- 下一次只改变一个主要变量；
- 两个日期的结果可以直接比较。
