## 吉他：完整能力主线

| 阶段 | 重点 | 可验证结果 |
|---|---|---|
| 定位 | 完整歌曲、节拍器循环、技术/指板/耳朵基线 | 找到第一个未通过关卡 |
| 0–1 | 基本操作与节奏吉他 | 不断拍完成歌曲，能口数细分 |
| 2–3 | 单音技术与指板 | 杂音可控，6/5 弦音名和八度可用 |
| 4–5 | 和声、耳朵与扒歌 | 能解释进行并独立找出短片段 |
| 6A/6B | 民谣与电吉他分支 | 能选择合适织体、消音与音色 |
| 7–8 | 即兴与编曲 | 围绕目标音说句子，声部互不打架 |
| 9 | 高阶整合 | 听到、找到、理解并改成自己的版本 |

## 声乐：从感觉到歌曲

安全与恢复 → 稳定发声 → `G4/A4` 区域与混声协调 → 小音量和弱唱 → 旋律线与英文节奏 → 选调、改编与完整歌曲。

## 数学物理乐理：从声音到音乐

振动与波 → 基频与泛音 → 八度和对数音高 → 十二平均律 → 音程与音阶 → 三和弦、七和弦与功能 → 节拍、重音与 groove。

## 歌曲练习与分析

统一处理顺序：版本与结构 → 根音与和声 → 节奏和重音 → 旋律/声部 → 技术难点 → 最小可演出版本 → 录音复盘。

首批案例包括 *Don't Look Back in Anger*、*Falling Slowly*、*Where We've Been* 与 *When You Sleep*（Friko 版本）。

## 布鲁斯口琴：A / Bb 第二把位

你的 A 调琴对应 E 调第二把位；Bb 调琴对应 F 调第二把位。路线从 2 孔吸音根音和单音乐句开始，之后才加入 3 孔、4 孔压音和完整蓝调音阶。

:::note[完整目录不等于当前任务]
教程把未来内容全部放进目录，是为了不丢路线；个人学习进度仍停在定位 A。完成证据出来前，不自动进入定位 B 或第 1 周。
:::
