## 吉他：完整能力主线

| 阶段 | 重点 | 可验证结果 |
|---|---|---|
| 定位 | 完整歌曲、节拍器循环、技术/指板/耳朵基线 | 找到第一个未通过关卡 |
| 0–1 | 基本操作与节奏吉他 | 不断拍完成歌曲，能口数细分 |
| 2–3 | 单音技术与指板 | 杂音可控，6/5 弦音名和八度可用 |
| 4–5 | 和声、耳朵与扒歌 | 能解释进行并独立找出短片段 |
| 6A/6B | 民谣与电吉他分支 | 能选择合适织体、消音与音色 |
| 7–8 | 即兴与编曲 | 围绕目标音说句子，声部互不打架 |
| 9 | 高阶整合 | 听到、找到、理解并改成自己的版本 |

执行入口：[前 8 个训练周](../guitar/first-8-weeks/) → [第 9–16 训练周](../guitar/stage-b-weeks-9-16/) → [第 17 训练周后的作品关卡](../guitar/post-16-gates/)。最后一页把完整扒歌、两个分支、即兴、编曲和高阶整合接成可复测任务，并说明如何交接给后续模块。

每关有必需项与可继续补强项；只做了原课的首轮一形一调，不自动记成整课完成。Neo 的主题号、PDF 页与待核视频入口分开记录。

## 声乐：从感觉到歌曲

安全与恢复 → 固定定位 → 1–2分钟短专项跟练中心 → 基础发声协调 → 头声/换区/混声 → 弱唱/动态 → 音准/旋律记忆 → 英文语流 → 前8个能力单元 → 难句、选调与完整歌曲。

声乐模块把“练”和“读教程”分开：短专项卡负责实际发声、准备时间、钢琴示范、移调间隔与收尾休息；正文负责原理、排错和通关。首轮交付不是最高音，而是可重复的基础协调、小音量清楚发声、脱离示范的短旋律，以及一首适合自身调性的完整录音。

## 数学物理乐理：从声音到音乐

测量与模型边界 → 振动与波 → 基频/泛音/音色包络 → 八度和对数音高 → 十二平均律/音分/拍频 → 音程与音阶 → 三和弦、七和弦与功能 → 节拍/重音/groove → 曲式、张力与编曲。

配套的八节实验要求每次完成预测、单变量操作、三次观察、模型解释、失效边界与乐器迁移。

## 歌曲练习与分析

统一处理顺序：版本卡与证据等级 → 结构 → 根音与和声 → 节奏和重音 → 旋律/声部 → 技术与音色 → 骨架版/段落版/个性版 → 不剪辑录音与单变量复盘。

先用[原创八小节完整案例](../songs/worked-example/)学习版本卡、时间点、分声部核验和两版编配；再迁移到 *Don't Look Back in Anger*、*Falling Slowly*、*Where We've Been* 与 *When You Sleep*（Friko 版本）。四首真实歌曲是带来源的练习项目，未核验的和弦、音域等仍明确待验证。

共用的[听觉实验室](../listening-lab/)提供 E2-v1/E4-v1 短句与答案、持续主音、拍频和固定音集合的中心对比；在相关课程中按需使用。

## 布鲁斯口琴：A / Bb 第二把位

你的 A 调琴对应 E 调第二把位；Bb 调琴对应 F 调第二把位。路线从乐器确认、定位、单音、2 孔吸音根音和吐音开始，再进入 I–IV–V、前 8 周、3/4 孔压音、motif/问答、完整 12 小节、吉他配合与维护排错。

## 每个模块都具备的课程部件

- 从哪里开始：定位或基础入口；
- 为什么：物理、结构或动作模型；
- 怎么练：时长、次数、速度/调性和步骤；
- 错在哪里：常见错误与回退方法；
- 怎样算完成：可重复的通关证据；
- 怎样合流：歌曲、录音或跨乐器任务。
