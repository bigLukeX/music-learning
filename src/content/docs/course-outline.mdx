## 吉他：完整能力主线

| 阶段 | 重点 | 可验证结果 |
|---|---|---|
| 定位 | 完整歌曲、节拍器循环、技术/指板/耳朵基线 | 找到第一个未通过关卡 |
| 0–1 | 基本操作与节奏吉他 | 不断拍完成歌曲，能口数细分 |
| 2–3 | 单音技术与指板 | 杂音可控，6/5 弦音名和八度可用 |
| 4–5 | 和声、耳朵与扒歌 | 能解释进行并独立找出短片段 |
| 6A/6B | 民谣与电吉他分支 | 能选择合适织体、消音与音色 |
| 7–8 | 即兴与编曲 | 围绕目标音说句子，声部互不打架 |
| 9 | 高阶整合 | 听到、找到、理解并改成自己的版本 |

## 声乐：从感觉到歌曲

定位与说话基线 → 安全与恢复 → 气流/声带振动/声道协调 → `G4/A4` 区域与混声 → 小音量和弱唱 → 音准/旋律记忆 → 英文节奏 → 前 8 周 → 选调、改编与完整歌曲。

首轮交付不是最高音，而是同一句三次重复、小音量清楚发声、脱离原唱的短旋律，以及一首适合自身调性的完整录音。

## 数学物理乐理：从声音到音乐

测量与模型边界 → 振动与波 → 基频/泛音/音色包络 → 八度和对数音高 → 十二平均律/音分/拍频 → 音程与音阶 → 三和弦、七和弦与功能 → 节拍/重音/groove → 曲式、张力与编曲。

配套的八节实验要求每次完成预测、单变量操作、三次观察、模型解释、失效边界与乐器迁移。

## 歌曲练习与分析

统一处理顺序：版本卡与证据等级 → 结构 → 根音与和声 → 节奏和重音 → 旋律/声部 → 技术与音色 → 骨架版/段落版/个性版 → 不剪辑录音与单变量复盘。

首批案例包括 *Don't Look Back in Anger*、*Falling Slowly*、*Where We've Been* 与 *When You Sleep*（Friko 版本）。

## 布鲁斯口琴：A / Bb 第二把位

你的 A 调琴对应 E 调第二把位；Bb 调琴对应 F 调第二把位。路线从乐器确认、定位、单音、2 孔吸音根音和吐音开始，再进入 I–IV–V、前 8 周、3/4 孔压音、motif/问答、完整 12 小节、吉他配合与维护排错。

## 每个模块都具备的课程部件

- 从哪里开始：定位或基础入口；
- 为什么：物理、结构或动作模型；
- 怎么练：时长、次数、速度/调性和步骤；
- 错在哪里：常见错误与回退方法；
- 怎样算完成：可重复的通关证据；
- 怎样合流：歌曲、录音或跨乐器任务。
